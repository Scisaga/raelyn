# Raelyn V2 信息架构

## 文档职责

本文定义 V2 的目标信息架构、核心界面、对象关系和跨页面状态。它描述完整产品，不以当前路由或接口是否已经存在为页面取舍依据。

- 产品定义见 [Raelyn V2 产品愿景](../vision.md)。
- 核心界面结构见 [V2 核心界面线框规范](../ui/wireframes-v2.md)。
- 当前实现事实和缺口见 [V2 现状能力差距](capability-gap-v2.md)。
- 已实现 UI 行为见 [UI 设计总览](../ui/overview.md)。

## 架构结论

V2 不再以“概览、媒体、视频、播放列表、任务”的后台功能分类组织产品，也不把“今日观察、星图、事件流、故事、简报”继续拆成五个彼此竞争的认知入口。

信息架构围绕一个中心建立：

> 用户进入一个观测域，在同一座星域观测台中看见变化、回放时间、追踪故事并验证证据。

星域观测台是默认首页和主工作空间；事件流是它的线性替代视图，故事与简报是它的长期阅读视图，播放列表是当前观测域按日复盘原始来源的工作台。信源管理、来源记录管理和运行状态属于支撑层。

## 信息架构原则

### 观测域是范围，不是普通内容页

观测域定义用户正在观察哪个世界。切换观测域会切换星域、故事、简报、观察游标、信源范围和域设置，但不会把用户带回一个播放列表卡片页。

### 星域是主空间，不是可视化附件

星域占据主要视口。变化摘要、故事更新、简报解释和事件详情以图层、侧轨或检查器进入，不把主空间压缩成仪表盘中的一张小卡片。

### 同一对象拥有多种视图

星域、观察流、故事、简报和证据检查器共享同一套真实事件、稳定身份、时间语义与筛选状态。它们不是各自生成一份相似数据。

### 产品层与运行层分离

任务、Worker、数据库、对象存储和模型调用不常驻认知界面。异常时从受影响对象浮现，正常时退居运行中心。

### 全局资料库完整存在但不主导叙事

信源管理和来源记录是必要的全局能力，分别承接当前媒体列表和视频列表。它们负责观测配置与证据档案，不替代星域观测台成为首页。

### 语义回放与来源播放彼此独立

星域回放使用事件发生时间观察真实事件、主题和故事如何进入固定语义空间；播放列表使用来源内容时间按日组织当前观测域中已具备播放资产的记录。两者共享观测域和返回上下文，但使用不同对象、时间步长和操作目标，不能用资料库单条详情或星域时间轴代替来源播放。

## 产品对象

| 产品对象 | 用户理解 | 主要关系 |
| --- | --- | --- |
| 观测域 | 一个长期关注的世界 | 包含信源范围、星域、故事、简报和观察游标 |
| 星域快照 | 某次构建完成的语义世界版本 | 冻结真实事件、主题、关系与坐标 |
| 星域变化集 | 两个观察状态之间发生的变化 | 连接快照、稳定身份与用户观察游标 |
| 主题 / 星群 | 语义邻近的事件区域 | 包含真实事件，不自动表达因果 |
| 真实事件 / 星点 | 多条记录共同描述的一件现实事件 | 拥有成员记录、证据、实体、故事与身份谱系 |
| 故事 / 航迹 | 有证据的事件发展序列 | 拥有稳定身份、版本、成员变化与关系证据 |
| 事件记录 | 一次内容分析形成的结构化陈述 | 指向来源记录与证据片段 |
| 证据 | 支撑事件或关系的原始材料位置 | 指向标题、描述、转写区间和来源记录 |
| 观测简报 | 对一个时间窗口与星域状态的解释 | 结构化引用事件、故事、证据和来源 |
| 信源 | 持续提供内容的频道或账号 | 可属于一个或多个观测域 |
| 来源记录 | 一次原始内容观测 | 包含视频、字幕、转写、资产和事件反向引用 |

当前内部对象映射与实现缺口不在本表中混写，统一见 [V2 现状能力差距](capability-gap-v2.md)。

## 上下文层级

### 全局观测站

不依赖某个观测域，负责：

- 观测域目录与创建；
- 全局搜索与命令；
- 全部信源和来源记录；
- 运行中心；
- 智能体接入；
- 系统设置。

### 当前观测域

承载用户大多数时间所在的认知空间：

- 星域观测台；
- 观察流；
- 故事；
- 简报；
- 播放列表；
- 当前域设置。

### 当前观察状态

在当前观测域内持续保留：

- 当前快照与对比基线；
- 用户最后观察游标；
- 时间窗口与播放位置；
- 当前观察模式；
- 事件类型、实体与主题筛选；
- 当前选中的主题、事件、故事或证据；
- 镜头状态与详情返回路径。

### 对象检查器

主题、真实事件、故事、证据和来源记录默认在当前工作空间中展开，而不是每次跳往没有上下文的孤立页面。需要深度阅读时再进入持久 URL。

## 全局应用壳

### 品牌与观测域切换器

侧栏顶部固定包含：

- Raelyn 事件视界标识；
- 当前观测域名称与状态；
- 切换观测域；
- 新建观测域；
- 返回观测域目录。

观测域切换器是全局范围控制器，不是侧栏中的普通菜单项。

### 主导航

认知层只保留五个入口：

1. **星域**：默认首页；当前形态、变化、回放、观察流和对象检查器；
2. **故事**：持续航迹目录、更新与深度阅读；
3. **简报**：按时间窗口阅读星域解释；
4. **播放列表**：按日浏览当前观测域中可播放的来源记录，连续播放并核对转写；
5. **资料库**：全局信源与来源记录，自动带入当前域筛选但可切换到全局。

“播放列表”固定放在“简报”下方、“资料库”上方。它是当前观测域工作流，不恢复旧的播放列表目录、事件审核列或周期简报列。

系统层独立成组：

- 运行中心；
- 智能体接入；
- 设置。

“事件”不需要与星域并列成为额外的一级产品中心。完整事件列表通过星域中的“观察流 / 列表视图”进入，并保留可分享路由。

### 顶部状态栏

顶部状态栏只显示当前任务所需信息：

- 页面或对象标题；
- 当前观测域与观察时间口径；
- 搜索 / 命令入口；
- 星域更新时间；
- 系统异常入口。

队列数、24 小时成功数、存储和模型 token 不常驻。存在失败、暂停、数据陈旧或服务不可用时，才显示可行动状态。

## 核心界面一：星域观测台

### 首要问题

> 我的关注世界现在是什么形态，自上次观察以来发生了什么？

### 视口结构

星域占据除 App Shell、工具栏和时间轴外的全部主视口。其上叠加三个按需层：

- **观察流**：靠右的窄侧轨，展示变化而不遮挡主要星域；
- **对象检查器**：选中主题、事件或故事后从右侧展开；
- **简报解释层**：按需展开，与星域中的引用双向定位。

页面下方固定时间轴。搜索、筛选、镜头和观察模式位于单行工具栏。除异常外，不在星域下方继续堆叠仪表盘卡片。

### 观察模式

#### 现在

- 默认停在当前时间窗口；
- 以变化光环、轮廓或短暂入场标记自上次观察以来的对象；
- 观察流按重要程度与时间列出新增事件、故事更新、新证据、纠正和身份变化；
- 点击变化只选中对象，不擅自改变镜头；“定位”才聚焦。

#### 回放

- 从一个明确起点向当前时间播放事件发生过程；
- 星点依据发生区间进入或离开，坐标保持不变；
- 星群密度变化必须可感知，但不制造虚构轨迹、残影或镜头漂移；
- 时间轴显示当前窗口、事件密度与关键更新标记。

#### 故事

- 选中一条故事后点亮其成员与有证据关系；
- 其他事件保留为空间背景但降低视觉权重；
- 时间播放可以沿故事航迹逐步展开；
- 用户可从任一节点进入事件或证据，也可进入完整故事页。

#### 验证

- 选中真实事件、故事边或简报引用后显示证据覆盖；
- 检查器按“结论 → 事件记录 → 原文片段 → 来源记录”展开；
- 缺失证据、低置信、时间不精确和冲突必须显式显示。

### 观察流

观察流不是通知中心，而是星域变化的线性解释。它包含四种稳定口径：

| 分组 | 回答的问题 | 时间 / 变化依据 |
| --- | --- | --- |
| 新发生 | 现实世界刚发生了什么？ | `event_time` |
| 新进入星域 | 系统新认识到了什么？ | 首次进入可浏览星域的变化记录 |
| 故事更新 | 哪些持续故事有了新发展？ | 故事版本差异 |
| 待审核 | 哪些候选事实尚未进入可信星域？ | 审核状态与证据完整性 |

历史回填可能属于“新进入星域”，不能标记成“刚发生”。同一对象可以同时属于新发生和新进入星域，但界面必须分别解释两个时间。

### 对象检查器顺序

#### 主题

1. 主题名称与当前窗口范围；
2. 星群密度和相对变化；
3. 代表真实事件；
4. 活跃故事；
5. 相关简报段落；
6. 主题解释与技术信息。

#### 真实事件

1. 发生了什么；
2. 事件时间、首次进入星域时间和最近变化；
3. 所属主题与相关故事；
4. 成员事件记录及其来源差异；
5. 实体与结构化关系；
6. 可验证证据；
7. 来源记录与转写定位；
8. 合并、拆分或延续谱系；
9. 技术 ID、快照和模型口径。

#### 故事

1. 故事现在发展到哪里；
2. 自上次观察以来新增的成员、证据或纠正；
3. 按发生时间排列的事件航迹；
4. 每条关系的类型与依据；
5. 相关简报段落；
6. 进入完整故事页。

## 核心界面二：事件列表

事件列表是星域的非空间替代视图，使用同一时间窗口、筛选和对象身份。

### 模式

- **新发生**：按事件发生时间排序；
- **新进入星域**：按进入可信星域的时间排序；
- **全部事件**：按发生时间浏览当前域事件档案；
- **待审核**：审阅候选事件与证据；
- **身份变化**：查看合并、拆分、退休与纠正。

列表中选择对象后，可以在右侧打开同一检查器或执行“在星域定位”。在不支持 WebGL2、移动端复杂操作或辅助技术场景中，事件列表承担完整替代路径，而不是功能缩水的 fallback。

## 核心界面三：故事

### 故事目录

故事目录回答：

- 哪些事情正在持续发展？
- 哪些故事自上次观察以来发生更新？
- 哪些故事获得了新证据、响应或纠正？

每个故事条目显示稳定标题、当前阶段、起止时间、最近更新时间、成员数量、变化类型和证据状态。故事可关注、取消关注、标记已读，并保留最后阅读位置。

### 故事阅读器

故事阅读器由三个同步区域组成：

- 左侧或主区域：按事件发生时间排列的故事时间线；
- 右侧：当前节点和关系的证据检查器；
- 背景或可切换区域：故事在星域中的航迹。

故事拥有稳定身份；一次星域快照只生成它的一个版本。版本差异明确列出成员新增、成员移除、关系变化、证据变化和生成性摘要版本。

## 核心界面四：星域简报

简报不是孤立 Markdown，而是一个带引用的星域解释器。

### 结构

- 周期标题、时间窗口、快照和生成口径；
- 本期星域概览；
- 主要变化；
- 持续故事；
- 新证据与纠正；
- 待确认事项；
- 结构化引用。

### 双向交互

- 悬停或点击事件引用，在星域中高亮对应星点；
- 点击故事引用，点亮航迹并切换相同时间窗口；
- 点击证据引用，打开原文片段；
- 从主题、事件或故事检查器可定位到解释它的简报段落；
- 阅读简报不改变事实对象，只保存阅读游标和显示上下文。

### 生成设置与批量操作

- “自动简报周期”和“简报生成提示词”属于简报页的生成设置，不再控制播放列表日历或来源记录列表；
- 日、周、月是简报生成口径和阅读筛选，不是来源播放的时间步长；
- “重新生成全部简报”改为显式“批量生成”操作，先选择粒度和日期范围、展示预计周期数，再确认投递；
- 批量生成完成后在运行中心查看任务，不把大量任务隐藏在普通设置保存反馈中。

## 核心界面五：来源播放列表

播放列表回答：

> 当前观测域在某一天收录了哪些可播放的原始材料，我如何连续观看并核对转写？

### 数据范围

- 只读取当前观测域关联信源中的来源记录；
- 默认使用内容时间，并按项目时区归入自然日；
- 只在列表中展示已经具备可播放资产的记录；未下载、失败或仅有元数据的记录继续在资料库中管理；
- 日历上的数量与当日列表使用完全相同的观测域、时间口径和可播放条件。

### 桌面结构

- 顶部固定工具条：当前日期、可播放数量、时间口径说明和明确的跨页快捷入口；
- 左侧约 36%–40%：当日来源记录列表，独立滚动；
- 右侧约 60%–64%：播放器为主，转写、元数据和前后记录控制置于播放器下方或同一详情面板；
- 底部固定 64px 按日滑动日历，始终控制当前列表；
- 页面不恢复旧版事件审核列、周期简报列、分析子视图或设置子视图。

### 选择与恢复

- 选择日期后加载当天列表并选中可恢复的记录；没有历史选择时默认选中第一条，但不自动发声；
- 选择记录只切换播放器和转写，用户显式播放后才产生声音；
- URL 至少保存 `domain_id`、`date`、`video_id` 和播放秒数，刷新或从资料库、简报、运行中心返回时恢复同一上下文；
- 当前记录被移出观测域或失去播放资产时，明确提示原因并选择相邻可播放记录，不静默播放另一条内容；
- 星域时间窗口与播放列表日期可以互相带入，但不共享同一个“播放”控制状态。

### 设置边界

播放列表页面不提供业务设置齿轮。真正的播放偏好，例如速度、自动连播和转写版本，使用播放器内即时控件；需要持久化时优先保存为用户本地偏好。原播放列表设置按职责迁移：

| 原设置 | 新归属 |
| --- | --- |
| 名称、描述、头像、背景 | 当前观测域设置 |
| 关注标的 / 媒体范围 | 资料库的当前观测域信源范围 |
| 简报粒度、提示词 | 简报生成设置 |
| 重新生成全部简报 | 简报批量生成 |
| 事件补齐、全量重抽、停止任务、星域重建 | 运行中心的当前域数据维护 |
| 删除播放列表 | 当前观测域设置中的“删除观测域” |

## 观测域目录

观测域目录用于选择要进入的世界，不承担旧版概览仪表盘职责。

每个观测域展示：

- 名称、说明与关注问题；
- 基于真实快照生成的迷你星域；
- 当前时间边界与最近更新；
- 自上次观察以来的变化数量与故事预览；
- 数据新鲜度与异常状态；
- 直接恢复上次观察状态的操作。

没有 ready 星域时显示明确的建立过程和下一步，不使用会被误解为真实数据的装饰星图。

## 当前观测域设置

观测域设置从侧栏顶部的当前观测域切换器旁通过明确的设置按钮进入，不占用一级主导航，也不藏在播放列表页面中。

首版只保留两组：

- **身份与呈现**：名称、描述、头像和背景图；
- **危险操作**：删除当前观测域。

信源数量、简报策略和数据处理状态可以显示摘要，但编辑操作分别跳转资料库、简报和运行中心，不在观测域设置中重复实现。删除确认必须展示信源关联、简报、星域快照、变化、故事和观察状态等域内数据的影响摘要，并要求输入观测域名称；不得继续使用“仅删除播放列表和简报”的不完整提示。

## 资料库

资料库是全局对象，默认继承当前观测域筛选，也可以切换为“全部”。

### 信源

对应当前媒体列表，负责管理观测仪器：

- 新增、导入、导出；
- 同步近期或全部历史；
- 监控开关与同步状态；
- 所属观测域；
- 最近内容与数据新鲜度；
- 来源异常和自动停用原因。

当前观测域范围下，主操作使用“加入信源”，可从全部资料中搜索已有信源，也可通过 URL 新建并在同一事务中加入当前域。行级移除使用“从当前观测域移除”，不得调用全局删除；全局永久删除只出现在全部资料的信源详情危险区。监控开关影响全局 `Media` 时，界面必须明确标注“全局监控”。

### 来源记录

对应当前视频列表及相关资产，负责管理原始观测档案：

- 平台时间、内容时间与入库时间；
- 下载、字幕、转写、事件和资产状态；
- 播放器与原始链接；
- 转写文本与精确时间 / 字符定位；
- 该记录支撑的事件、故事关系和简报引用；
- 所属信源和观测域；
- 处理记录与重新处理入口。

转写与证据默认是来源记录详情的一部分。只有当跨记录全文或语义检索成为独立高频任务时，才增加全局证据搜索入口；无论是否独立成页，都必须保持反向引用能力。

## 全局搜索与命令

搜索按对象类型分组：

- 观测域；
- 主题；
- 真实事件；
- 故事；
- 实体；
- 简报；
- 信源；
- 来源记录；
- 设置和运行命令。

搜索结果必须说明所属观测域和时间上下文。跨观测域搜索可以命中多个独立星域并进入对应位置，但不能把不同投影中的坐标拼成一张虚假全局星图。

## 运行中心

运行中心统一承载：

- 活动与历史任务；
- 任务进度、错误、取消和重试；
- Worker 心跳与角色；
- 数据库、对象存储、ASR、Embedding 和 LLM 服务；
- 存储占用与模型调用；
- 观测域级采集、事件抽取、向量和星域构建质量；
- provider 或系统暂停。

补齐事件抽取、全部重新抽取、停止抽取任务和构建星域快照集中在运行中心的“当前域数据维护”区。所有操作必须显示范围、预计影响和当前活跃任务；从星域、简报或播放列表进入时携带来源页面与观测域，完成或取消后可以返回原上下文。

从星域异常入口进入时，运行中心自动带入受影响的观测域、对象和任务筛选。

## 智能体接入

智能体接入不是单纯的 MCP 配置说明，而是 Raelyn 语义世界的程序化入口。目标对象包括：

- 观测域及其当前变化；
- 真实事件、主题、故事和证据；
- 简报与结构化引用；
- 信源、来源记录和转写；
- 安全的异步观测任务。

Web、REST 和 MCP 使用相同稳定身份与时间语义，不为智能体另建一套无法和 UI 对齐的对象模型。

## 时间与变化语义

界面统一区分：

| 标签 | 含义 |
| --- | --- |
| 发生于 | 现实事件发生或覆盖的时间区间 |
| 内容时间 | 来源内容实际对应的时间 |
| 平台发布于 | 平台记录的发布时间 |
| 来源入库于 | 系统首次保存来源记录的时间 |
| 事件记录收录于 | 系统首次获得该条分析记录的时间 |
| 进入星域于 | 真实事件首次进入可浏览星域的时间 |
| 故事更新于 | 故事版本最近发生结构变化的时间 |
| 上次观察于 | 用户最后确认观察状态的游标时间 |
| 快照完成于 | 当前星域版本构建完成的时间 |

“新”永远带明确基线：新发生、新收录、新进入星域或自上次观察以来更新。界面不使用没有口径的“最近”“今日热点”或“刚刚发生”。

## 跨界面路径

### 回访与发现

```text
恢复上次星域
→ 播放到现在
→ 选择一处变化
→ 真实事件或故事
→ 证据
→ 原始来源
```

### 故事跟踪

```text
故事更新
→ 查看本次新增成员 / 证据 / 纠正
→ 在星域点亮航迹
→ 打开事件节点
→ 核验证据
```

### 简报理解

```text
星域简报
→ 点击事件或故事引用
→ 恢复对应时间窗口并定位星域
→ 证据检查器
→ 来源记录
```

### 来源反查

```text
来源记录
→ 转写片段
→ 由该片段支撑的事件
→ 所属故事与星域位置
→ 相关简报段落
```

### 来源连续复盘

```text
播放列表日历
→ 选择日期与来源记录
→ 播放并核对转写
→ 打开来源记录详情或证据关系
→ 返回同一日期、记录和播放位置
```

### 调整观测范围

```text
资料库 · 当前观测域
→ 从全部资料选择已有信源，或通过 URL 新建并加入
→ 后台刷新受影响周期并标记星域待更新
→ 返回原播放日期或星域上下文
```

### 异常处理

```text
对象上的异常提示
→ 带上下文进入运行中心
→ 任务 / 服务 / 数据质量详情
→ 处理后返回原对象
```

## 响应式与可访问性

### 桌面

- 星域、观察流、时间轴和对象检查器可以同时协作；
- 观察流与检查器按需覆盖，不永久压缩星域；
- 故事与简报支持星域同步定位；
- 播放列表保持左侧记录列表、右侧播放器与底部日历同时可见，列表和转写各自独立滚动。

### 平板

- 侧栏折叠为图标栏或抽屉；
- 观察流和对象检查器互斥展开；
- 星域仍是默认首屏，时间轴保持完整；
- 播放列表采用播放器在上、记录列表在下，底部日历保持固定；转写使用覆盖面板。

### 手机

- 星域默认全屏；
- 观察流、筛选、详情和简报使用逐层抽屉；
- 事件列表提供完整的非空间替代路径；
- 故事时间线、简报和证据阅读保持完整；
- 不通过改变坐标或事实集合制造移动端版本；
- 播放列表优先显示播放器，记录列表和转写通过标签或底部抽屉切换，按日日历保持可横向滑动。

### 可访问性

- 所有颜色同时有文字、形状或状态标签；
- 导航、搜索、时间轴、观察流、主题、事件和详情可由键盘操作；
- 星域内容拥有事件列表等价入口；
- `prefers-reduced-motion` 下停止自动播放、持续旋转和入场动画；
- 暂停动画后仍能读取同一变化信息；
- 时间、ID 与数值使用稳定的 tabular 排版。

## 目标验收标准

- 进入已有观测域后直接恢复星域观测台，而不是进入统计仪表盘或内容卡片墙；
- 星域始终是主视觉，观察流、检查器和简报作为图层与其协作；
- 用户可以从上次观察状态播放到现在，并看见星域密度和故事轨迹的变化；
- 新发生、新进入星域、故事更新和待审核拥有准确且独立的口径；
- 真实事件和故事可以跨快照连续回访，合并、拆分与纠正可解释；
- 星域、事件列表、故事和简报共享稳定身份、时间窗口和筛选状态；
- 播放列表作为“简报”与“资料库”之间的一级入口，完整保留按日日历、当日列表和播放器，不再包含事件、简报或运维设置子视图；
- 播放日期、记录和播放位置可通过深链接恢复，简报粒度不会改变播放日历；
- 当前域信源可以从全部资料中加入，移除关联与全局删除拥有不同文案、接口和确认边界；
- 任意事实结论都能沿明确路径返回证据片段和原始来源；
- 全局信源与来源记录能力完整，但不取代星域成为产品首页；
- 正常运行状态退居背景，异常能携带上下文一跳处理；
- 没有装饰星点、虚构故事边、伪趋势或被误认为数据的视觉效果。
