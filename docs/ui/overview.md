# UI 设计总览

本文记录当前已经实现的 UI 结构与主要交互，而不是早期草图。

项目当前配色主题重载见 [UI 主题配色](theme.md)。

## 技术形态

- 运行时：FastAPI 提供静态 SPA。
- 前端源码：`ui/`
- 构建产物：`static/`
- 技术栈：TailwindCSS + Alpine.js
- 资源策略：不依赖 CDN，样式、脚本、PWA 资源都从本地静态目录加载。

## 当前页面结构

### 启动门面

- 应用启动时先显示全屏启动门面，底层是基于 WebGL Fluid Simulation 的流体 canvas。
- 启动阶段文案继续叠在 canvas 上，启动阶段仍会依次探测系统状态、资源分发策略和概览首屏资源。
- 若主站 API 开启 Bearer Token，会在同一层启动门面中显示 token 输入框，不切换到独立页面。
- 当系统启用减少动态效果时，启动门面的圆球、加载点等 CSS 动画会停用，但 WebGL 流体背景仍保持可见；只有当前环境 WebGL 初始化失败时才会回退到静态深色渐变背景。

### 侧边导航

当前导航项：

- 概览
- 媒体
- 视频
- 播放列表

## 当前页面能力

### 概览页

- 展示媒体数、视频数、待处理任务、失败任务等统计。
- 概览页的大额调用数与 token 数使用 `K/M/G/T` 等紧凑单位展示，避免服务状态卡片横向溢出。
- 展示最近媒体、最近视频、热门播放列表卡片。
- 播放列表卡片会带最近简报摘要片段。

### 媒体页

- 列表展示媒体头像、名称、provider、监控开关、本地视频数。
- 支持新增媒体、导入媒体、导出媒体。
- 新增媒体后默认未启用监控。
- 支持“同步近期视频”和“同步全部历史视频”。
- 支持开启 / 关闭监控。
- 自动停用的媒体会显示原因标签，例如 YouTube 频道不存在时显示“来源不可用”。
- 直接进入媒体页时，首屏只请求当前列表页数据；向下滚动到列表底部后继续按页加载更多媒体。媒体选择器所需的轻量媒体索引延后到创建播放列表、视频筛选等交互入口加载。
- 当资源分发已回退为 `/api/assets` 代理模式时，媒体列表请求不携带 S3 预签名 URL，头像通过代理内容地址加载，减少首屏服务端签名开销。

### 视频页

- 支持按媒体、状态、关键词、发布时间范围筛选。
- 列表展示封面、媒体头像、发布时间、状态、下载产物状态。
- 提供视频播放器弹窗。
- 在播放器内可查看 transcript、播放资产、重新转写、生成笔记。

### 播放列表列表页

- 展示播放列表概览卡片。
- 支持创建播放列表。
- 支持从概览页、媒体页等入口跳转到详情页。
- 直接进入播放列表列表页时，页面数据加载完成后再静默刷新 `/api/stats`，避免概览统计阻塞播放列表首屏展示。
- 播放列表创建 / 编辑使用 `/api/media/options` 加载轻量媒体选项，不在首屏请求完整媒体列表。

### 播放列表详情页

主视图：

- 顶部展示头像、背景图、标题、描述、媒体预览、视频数与时间范围。
- 中部包含视频列表、播放器；左侧栏在事件审核与当前周期总结之间切换。
- 事件审核默认按当前时间轴周期请求事件列表与状态计数，周期口径基于事件 `available_at`，避免把长期预测目标时间误读为当前期。
- 事件审核使用单列审核卡片流：卡片默认展示日期、状态、类型、置信度、摘要与实体，点击后在卡片内展开方向、幅度、超预期、影响链和证据；实体过滤框会按当前周期与状态展示实体推荐。
- 底部时间轴支持按天 / 周 / 月浏览周期。

设置子视图：

- 修改播放列表名称、描述与关注标的
- 上传 / 清除背景图
- 事件图谱数据维护区展示全量事件覆盖视频数 / 总视频数、全量事件状态计数与语义快照状态；summary 未加载完成时显示加载 / 未加载状态，空播放列表显示暂无视频，只有存在 ready run 时才显示“语义快照已就绪”。维护区提供补齐事件抽取、全部重新抽取、停止当前抽取任务与构建语义快照；如果存在正在执行的全量重抽任务，补齐事件抽取与全部重新抽取按钮均不可用，任务条分别展示月任务完成 / 待执行数、已执行月任务累计扫描 / 投递 / 跳过的视频数、已投递视频抽取子任务的已抽取 / 待抽取 / 执行中数量，以及已运行时间 / 预估总时长；预估总时长会把未扫描月份预计产生的视频抽取任务纳入估算，样本不足时显示估算中
- 重新生成全部简报
- 修改简报聚合粒度
- 编辑播放列表专属简报提示词
- 删除播放列表

分析子视图：

- 页面标题为“事件图谱”，展示播放列表级事件 embedding ready/total、就绪状态、不可入图数和失败数，并按 `趋势 / 事件` 两个 tab 组织语义快照结果。embedding 完全就绪不等于快照已经构建；没有 `last_ready_run_id` 时明确显示“尚未构建语义快照”，也不请求变化点接口。
- `趋势` tab 使用事件发生时间轴。页面先在播放列表内容起点与今天组成的“正常观察域”内请求月级 signal，以柱高提示各月进入语义快照的事件量，并默认选中截至今天最近有数据的 12 个月；未来 signal 不再影响首屏定位。完整 signal 边界仍来自兼容接口 `regime/summary`，当完整范围超出正常观察域时可由用户主动切换“全量”时间轴，不删除更早历史事件或未来事件。当前选区的多尺度信号继续按 `regime/signals?since=...&until=...` 请求，同一 ready run 与同一范围会复用前端缓存。趋势页先从 `signals.linked_candidate_id` 绘制语义变化点，再后台加载 `regime/candidates` 回填强度；变化点默认使用自适应展示，短范围展开单点，长范围按屏幕间距聚合。
- 折线图横轴与底部时间轴共享同一组选区起止日期；图表会按当前范围补齐自适应空白时间点作为日历轴，短范围使用日级锚点，长范围使用更稀疏锚点以降低首屏渲染成本；事件语义焦点窗位置独立按真实日期比例计算。
- 左图标题为“事件时间演化”，rolling z 的用户文案为“标准化语义变化”；日级曲线对低样本日期敏感，默认隐藏，并在 embedding 数不足或日期断档处断线。
- 右图标题为“焦点窗口周期语义轨迹”。每个点代表一个日级周期 centroid，仅用于观察相邻周期变化，不是事件级二维 embedding 地图；点颜色表示周期内语义分散度。焦点窗包含变化点时，额外显示变化点前后日级语义中心与归一化方向箭头。
- `事件` tab 按变化日期倒序展示语义变化点、检测来源、类型、强度、置信度、不确定性、摘要与代表证据视频；代表样本按候选周期 centroid 距离选取，不表示窗口内全部事件。
- 失败数来自当前 embedding 口径下 failed / skipped-over-budget 的 accepted 事件；不可入图数来自 accepted 事件缺少 `event_time_start` 或缺少有效 ready vector。已就绪但因年级精度不能进入当前日/周/月尺度的数量单列为 `event_scale_excluded`，不重复计入不可入图。
- 播放列表作为一个完整语料库，不按媒体来源拆分或加权；平台批量历史上架不会成为事件同日峰值，语义信号按 `event_time_start` 聚合。
- 若播放列表存在活跃的历史事件抽取任务，顶部只展示任务状态与扫描/投递进度；抽取、停止与重建操作集中放在播放列表设置页。
- 页面结构使用单体紧凑工具条（标题、状态、指标、tab、范围上下文、操作按钮合并布局）+ 条状任务/错误反馈 + 全高内容区；图表区与事件详情区按剩余高度自适应伸展，避免多层面板嵌套。
- 播放列表主视图的事件审核面板默认按可观察时间展示近期信息，并按 `time_precision` 显示事件目标时间：年级事件显示为 `YYYY年`，月级事件显示为 `YYYY-MM`，只有日级或秒级事件显示完整日期；鼠标悬停时间可查看可观察时间，避免把长期预测目标误读为精确发生日。

### 任务页

- 支持查看活动任务与已完成任务。
- 支持按类型、时间范围筛选。
- 支持实时刷新、查看错误详情、取消 / 重试任务。
- 包含任务统计图与实时任务快照。

### MCP Server 页面

- 说明 MCP Server 的连接地址、Bearer 鉴权、可用 tools / resources。
- 内置 VS Code / Codex CLI / OpenClaw 等接入示例。

### 设置页

当前标签页：

- `Cookies`
- `字幕`
- `会员`
- `画质`
- `LLM`
- `清理`
- `主屏幕`

各标签当前职责：

- `Cookies`：保存 YouTube / B 站 Netscape `cookies.txt`
- `字幕`：控制是否下载字幕 / 自动字幕
- `会员`：控制是否尝试下载 YouTube 会员专享视频
- `画质`：管理 `yt-dlp --format`
- `LLM`：编辑全局转写润色提示词
- `清理`：扫描并清理遗留 discovered 视频记录
- `主屏幕`：PWA 安装引导

## 当前交互特点

- 大多数写操作都会给出 toast，并可跳转到任务页查看异步执行结果。
- 任务页和概览页依赖 `/api/ws/jobs` 与 `/api/ws/job_stats` 做实时刷新。
- 概览页首屏依赖 `/api/stats`；其他页面启动时不等待 `/api/stats` 完成，统计信息允许延后静默刷新。
- 播放列表简报支持复制文本、打开原文、重新生成当前周期或全量重建。
- 设置页以运行时配置为主，保存后通常无需重启服务。

## 当前 UI 边界

- 还没有独立的“Briefs 列表页”；简报阅读主要放在播放列表详情页。
- UI 仍以单用户桌面 / 平板场景为主，移动端重点保障浏览、播放和 PWA 安装路径。
- MCP 页面是前端说明页，不等价于 MCP 实际 endpoint；真实接口由主 API 进程挂载在 `/mcp` 提供。
