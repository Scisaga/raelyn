# UI 设计总览

本文记录当前已经实现的 UI 结构与主要交互，而不是早期草图。

项目当前配色主题重载见 [UI 主题配色](theme.md)。

## 技术形态

- 运行时：FastAPI 提供静态 SPA。
- 前端源码：`ui/`
- 构建产物：`static/`
- 技术栈：TailwindCSS + Alpine.js
- 资源策略：不依赖 CDN，样式、脚本、PWA 资源都从本地静态目录加载。

## 当前页面结构

### 启动门面

- 应用启动时先显示全屏启动门面，底层是基于 WebGL Fluid Simulation 的流体 canvas。
- 启动阶段文案继续叠在 canvas 上，启动阶段仍会依次探测系统状态、资源分发策略和概览首屏资源。
- 若主站 API 开启 Bearer Token，会在同一层启动门面中显示 token 输入框，不切换到独立页面。
- 当系统启用减少动态效果，或当前环境 WebGL 初始化失败时，启动门面会自动回退到静态深色渐变背景。

## 当前页面能力

### 概览页

- 展示媒体数、视频数、待处理任务、失败任务等统计。
- 展示最近媒体、最近视频、热门播放列表卡片。
- 播放列表卡片会带最近简报摘要片段。

### 媒体页

- 列表展示媒体头像、名称、provider、监控开关、本地视频数。
- 支持新增媒体、导入媒体、导出媒体。
- 新增媒体后默认未启用监控。
- 支持“同步近期视频”和“同步全部历史视频”。
- 支持开启 / 关闭监控。
- 自动停用的媒体会显示原因标签，例如 YouTube 频道不存在时显示“来源不可用”。
- 直接进入媒体页时，首屏只请求当前列表页数据；向下滚动到列表底部后继续按页加载更多媒体。媒体选择器所需的轻量媒体索引延后到创建播放列表、视频筛选等交互入口加载。
- 当资源分发已回退为 `/api/assets` 代理模式时，媒体列表请求不携带 S3 预签名 URL，头像通过代理内容地址加载，减少首屏服务端签名开销。

### 视频页

- 支持按媒体、状态、关键词、发布时间范围筛选。
- 列表展示封面、媒体头像、发布时间、状态、下载产物状态。
- 提供视频播放器弹窗。
- 在播放器内可查看 transcript、播放资产、重新转写、生成笔记。

### 播放列表列表页

- 展示播放列表概览卡片。
- 支持创建播放列表。
- 支持从概览页、媒体页等入口跳转到详情页。
- 直接进入播放列表列表页时，页面数据加载完成后再静默刷新 `/api/stats`，避免概览统计阻塞播放列表首屏展示。
- 播放列表创建 / 编辑使用 `/api/media/options` 加载轻量媒体选项，不在首屏请求完整媒体列表。

### 播放列表详情页

主视图：

- 顶部展示头像、背景图、标题、描述、媒体预览、视频数与时间范围。
- 中部包含视频列表、播放器、当前周期简报预览。
- 底部时间轴支持按天 / 周 / 月浏览周期。

设置子视图：

- 上传 / 清除背景图
- 重新生成全部简报
- 修改简报聚合粒度
- 编辑播放列表专属简报提示词
- 删除播放列表

分析子视图：

- 展示播放列表级 embedding 覆盖率、跳过数、失败数，并按 `趋势 / 事件` 两个 tab 组织分析结果。
- `趋势` tab 使用统一时间轴，默认展示有数据的最近一年；全量时间轴边界来自 `analysis/summary`，信号数据按当前时间范围请求 `analysis/signals?since=...&until=...`，同一 ready run 与同一范围会复用前端缓存，拖动范围后再补取对应区间；底部使用精简月份范围拖拽条，月份刻度短于年份刻度，拖拽绿色范围整体平移，拖动边缘竖向把手调整边界；拖动过程中只更新底部时间轴预览，松手后才提交范围、重绘图表并重新加载 signals，避免长时间范围下拖拽卡顿；事件候选列表不阻塞趋势页首屏，趋势页先从 `signals.linked_event_id` 绘制候选断点，再后台加载 `analysis/candidates` 用 `boundary_z` 回填强度；候选断点默认使用自适应展示，短范围展开单断点，长范围按约 32px 屏幕间距聚合为断点簇，也可切换为 `自动 / 重要 / 密度 / 全部`；时间趋势图展示多尺度语义漂移 z、drift 与不确定性，本身不支持拖拽缩放；PCA 使用独立焦点窗口解释焦点窗口内日级语义分布，蓝色焦点窗显示在折线图绘图区并按真实日期坐标定位，支持 `3个月 / 6个月 / 1年 / 3年` 尺寸切换，播放按钮显示在趋势图标题行右侧，播放时约每 420ms 前进一个月；点击候选断点或断点簇会把 PCA 焦点窗移动到对应最强断点附近，焦点窗在折线图上拖拽时只移动窗口预览，松手后再刷新 PCA 点，避免长时间范围下每个 pointermove 都重排散点。
- 折线图横轴与底部时间轴共享同一组选区起止日期；图表会按当前范围补齐自适应空白时间点作为日历轴，短范围使用日级锚点，长范围使用更稀疏锚点以降低首屏渲染成本；PCA 焦点窗位置独立按真实日期比例计算。
- PCA 投影点颜色表示不确定性高低，绿色偏低、黄色偏高；颜色图例只解释点的可信度，不代表 PCA 横轴方向。焦点窗包含候选断点时，PCA 图额外显示断点前后日级语义中心与归一化方向箭头，箭头表达方向优先于真实距离，辅助解释断点两侧语义状态差异。
- 日级 rolling z 对低样本日期敏感，趋势页默认隐藏日线；手动打开时，日级曲线会在 embedding 数不足或日期断档处断线，避免把稀疏发布日期连成规则尖刺。
- `事件` tab 按事件日期倒序展示候选事件序列、检测来源、事件类型、强度、置信度、不确定性、摘要、关键词与证据视频；同日候选中开放式主题 `open_topic_burst_v1` 优先于语义漂移候选断点，开放式主题覆盖短爆发与持续主题窗口；不再展示训练 / 验证 / 测试窗口。
- 失败数来自当前播放列表内 `video_embedding.status == failed` 的视频数量；跳过数来自 transcript 超出 embedding 上下文预算的 `skipped_over_budget` 状态。
- 若播放列表存在活跃的历史 embedding 补算任务，顶部展示任务状态与扫描/写入进度，禁用新的补算入口，并提供停止当前补算任务的操作。
- 页面结构使用单体紧凑工具条（标题、状态、指标、tab、范围上下文、操作按钮合并布局）+ 条状任务/错误反馈 + 全高内容区；图表区与事件详情区按剩余高度自适应伸展，避免多层面板嵌套。

### 任务页

- 支持查看活动任务与已完成任务。
- 支持按类型、时间范围筛选。
- 支持实时刷新、查看错误详情、取消 / 重试任务。
- 包含任务统计图与实时任务快照。

### MCP Server 页面

- 说明 MCP Server 的连接地址、Bearer 鉴权、可用 tools / resources。
- 内置 VS Code / Codex CLI / OpenClaw 等接入示例。

### 设置页

当前标签页：

- `Cookies`
- `字幕`
- `会员`
- `画质`
- `LLM`
- `清理`
- `主屏幕`

各标签当前职责：

- `Cookies`：保存 YouTube / B 站 Netscape `cookies.txt`
- `字幕`：控制是否下载字幕 / 自动字幕
- `会员`：控制是否尝试下载 YouTube 会员专享视频
- `画质`：管理 `yt-dlp --format`
- `LLM`：编辑全局转写润色提示词
- `清理`：扫描并清理遗留 discovered 视频记录
- `主屏幕`：PWA 安装引导

## 当前交互特点

- 大多数写操作都会给出 toast，并可跳转到任务页查看异步执行结果。
- 任务页和概览页依赖 `/api/ws/jobs` 与 `/api/ws/job_stats` 做实时刷新。
- 概览页首屏依赖 `/api/stats`；其他页面启动时不等待 `/api/stats` 完成，统计信息允许延后静默刷新。
- 播放列表简报支持复制文本、打开原文、重新生成当前周期或全量重建。
- 设置页以运行时配置为主，保存后通常无需重启服务。

## 当前 UI 边界

- 还没有独立的“Briefs 列表页”；简报阅读主要放在播放列表详情页。
- UI 仍以单用户桌面 / 平板场景为主，移动端重点保障浏览、播放和 PWA 安装路径。
- MCP 页面是前端说明页，不等价于 MCP 实际 endpoint；真实接口由主 API 进程挂载在 `/mcp` 提供。
