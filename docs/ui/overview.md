# UI 设计总览

本文记录当前已经实现的 UI 结构与主要交互，而不是早期草图。

项目当前配色主题重载见 [UI 主题配色](theme.md)。

所有主界面共用深空表面系统：应用环境、页面气氛、工作表面、阅读表面、抬升详情和数据画布具有稳定的亮度层级，各页面只以低透明度青蓝、靛紫、青绿或中性蓝灰区分工作语境。星域 WebGL 画布保持接近纯黑，背景渐变不得覆盖事件类型、密度和选择状态；具体色值与共享类以主题文档为准。

## 技术形态

- 运行时：FastAPI 提供静态 SPA。
- 前端源码：`ui/`
- 构建产物：`static/`
- 技术栈：TailwindCSS + Alpine.js
- 资源策略：不依赖 CDN，样式、脚本、PWA 资源都从本地静态目录加载。

## 当前页面结构

### 启动门面

- 应用启动时先显示全屏“事件语义星域”门面。底层 WebGL canvas 使用 ready 事件地图生成的匿名真实数据样本：只保留量化三维坐标、事件时间、语义色、成员权重和随机相位，不包含标题、实体、canonical ID 或来源信息。
- 样本在固定语义坐标中按事件时间做 24 秒循环显隐，并仅使用缓慢镜头视差；事件点不会为了装饰而改变相对位置。桌面最多绘制 6,000 点，窄屏降为 1,800 点。
- 中央品牌图形使用非对称黑洞吸积盘和事件视界，不再使用玻璃球及外围同心圆；`RAELYN / 事件语义星域` 作为固定品牌层级，“输入访问令牌”只保留为表单提示。
- 启动阶段文案继续叠在 canvas 上。进入星域时，真实星图加载会与系统状态、资源分发策略探测并行启动；只有概览页仍等待自己的首屏数据与图片。
- 若主站 API 开启 Bearer Token，会在同一层启动门面中显示 token 输入框，不切换到独立页面。
- 登录前不能访问受 Bearer Token 保护的事件地图接口，因此动画读取构建时复制到 `/static/data/startup-event-field.bin` 的公开匿名样本，不在浏览器中请求私有标题或事件详情。样本可用以下命令从指定 ready 快照重新生成：

  ```bash
  .venv/bin/python scripts/dev/generate-startup-starfield.py \
    --playlist-id PLAYLIST_ID \
    --limit 6000 \
    --start-date 2008-05-24 \
    --end-date 2026-07-25
  ```

- 当系统启用减少动态效果时，星域停在固定时间切片，吸积盘和加载点等 CSS 动画停用；WebGL 或匿名样本加载失败时回退到静态深色渐变背景。

### 侧边导航

当前导航项：

- 星域
- 故事
- 播放列表
- 资料库
- 观测域设置
- 运行中心
- 资源用量
- 智能体接入
- 设置

说明：

- 侧栏品牌入口、浏览器 favicon 和 PWA 主屏幕图标统一使用“R 事件视界”标识：原品牌带衬线与叶片缺口的 R 保持大尺寸主体占比和黄绿—青色渐变；吸积盘沿用启动门面的遮挡关系，但只保留一张低饱和雾蓝—灰紫色倾斜椭圆盘和同盘的前缘，不与 R 争用青绿色相，也不叠加第二描边或独立高光。
- 品牌源文件位于 `ui/assets/brand/`；侧栏和 PWA 使用标准事件视界版本，浏览器 favicon 单独使用小尺寸光学校正版，启动门面使用从同一 R 路径提取的透明渐变字形。高清导出直接把 SVG 栅格化到目标分辨率，标准标识与透明字形 PNG 母版为 2048px、favicon PNG 母版为 1024px，禁止先按 SVG 默认 64px 解码后再放大。根目录 `logo.png`、`static/brand/logo.png` 与 `logo-y.png` 由标准 2048px 母版同步覆盖，`logo-r.png` 则由透明渐变字形母版生成；这些旧文件名只作为兼容入口，不再维护独立旧版图形。常规构建再从高清母版派生 favicon、Apple Touch 与 PWA 固定尺寸，运行时不依赖外部资源。
- 认知工作区与系统工作区分组展示；全局语义搜索位于顶栏，结果按观测域、主题、真实事件、故事、简报、信源与来源记录分组。
- 系统工作区内“资源用量”固定放在“运行中心”之后，规范路由为 `/usage`；它是独立一级页面，不是运行中心中的统计卡或设置页标签。
- `overview`、`media`、`videos`、`playlists`、`jobs` 是兼容旧链接的隐藏路由，不再作为 V2 主导航。
- 播放列表固定放在“故事”下方、“资料库”上方；规范路由为 `/domains/{domain_id}/playlist?date=YYYY-MM-DD&video_id=UUID&t=SECONDS`，简报只额外使用同一路由的 `tab=brief` 状态。时间粒度始终来自观测域配置，不由 URL 覆盖。旧 `/playlist?playlist_id=...` 与 `/briefs?domain_id=...&brief_id=...` 会保留上下文后归一化到该路由。
- 页面基于 History API 切换，非 `/api` 与 `/static` 路径会回退到 SPA 壳。

## 当前页面能力

### 星域页

- 星域是默认首页和主要操作空间，直接进入最近一次观测域；未创建观测域时展示创建引导，不用运维统计代替产品入口。
- 进入星域后立即显示与真实画布连续的空坐标网格，不短暂展示“尚未构建”或独立的文字进度面板。真实快照就绪后先提交只有远场穹幕与语义引力膜的 WebGL 帧，再以稳定顺序逐批显现真实事件点，最后让真实主题与事件标签从轻微模糊收清；该过程不生成装饰星点、不改变事件位置或类别，减少动态效果时直接呈现完整场景。后台更新已有快照时保留旧场景，待新场景首帧完成后再原位替换。
- 顶部不再提供“现在 / 回放 / 故事 / 验证”模式切换。时间回放由底部时间轴直接控制；故事和证据在选中对应对象时进入检查器。工具栏只保留“今日事件 / 本周事件”时间焦点、查找、筛选、适配和星域变化。
- “星域 / 列表”是同一组真实事件的两种互斥主视图，共用时间、事件类型与实体筛选；查找和筛选使用居中临时面板，不与主视图并排占据画布。“星域变化”只在星域主视图中出现，并与对象检查器复用同一条右侧上下文轨道。对象详情出现时优先占用轨道，“星域变化”入口不再保持伪激活；若详情从变化上下文进入，入口与详情关闭动作改为“返回变化”，返回后恢复原变化口径和阅读位置。
- 右侧“星域变化”区分“新发生、认知变化、故事更新、待验证”，并明确事件发生时间与系统认知时间的口径。该抽屉默认收起，只在用户打开时覆盖画布；故事和证据由对象选择直接打开对应检查器。
- 普通进入当前星域时以今天为截止日并展示最近 12 个自然月，不再被旧观察游标停留在历史日期。显式历史快照或带 `window_start/window_end` 的深链接仍可恢复指定时间窗；游标继续保存镜头、筛选和选中对象。
- 支持 canonical、topic、story 深链接，以及不依赖 WebGL 的类型化线性事件视图。
- 主题、真实事件和故事检查器均可反查解释它们的简报段落；topic 通过当前成员 canonical 聚合引用，不制造独立的主题事实引用。
- 三维渲染、时间轴、主题与证据详情的具体行为见下方“事件语义星域”。

### 故事页

- 故事页是更新阅读器，不是故事对象审计台。左侧提供“值得阅读 / 已关注 / 已形成 / 初步线索”四个独立搜索与分页队列；默认把已关注/读过故事的未读实质更新，以及观察基线后首次形成或事实结构发生变化的成熟故事放到用户面前，首访只推荐最近成熟故事。
- 目录每行只显示稳定标题、最新真实事件进展、实质变化标签、实质更新时间、关注与准确未读；不显示全库大数字、节点数、快照或技术 ID。
- 实质更新时间和识别审计时间是绝对时刻，按浏览器本地时区显示；故事中的现实事件时间继续保留来源精度，不把只有日期的事件伪造成精确时刻。
- 页头把冻结的故事主题与持续变化的最新进展分开，并显示现实时间跨度、事件/关系/支持记录数量、成熟度和最近实质更新时间。有未读实质更新时显示具名“自上次阅读后”与“从新增处继续”；若期间变化后又恢复原状则明确说明，不伪造净增减。打开详情或只保存位置不会自动标记已读，首访推荐仍可由用户显式建立阅读基线。
- 故事发展按现实发生时间完整展示。只有真实 incoming edge 才以中文关系附着到目标事件，不用连续竖线把相邻事件伪装成因果链；分支、非相邻关系和多来源关系保留原结构。
- 事件或关系被选择后才打开证据检查器；桌面使用右栏，平板和手机使用覆盖抽屉。关系支持记录按需加载，并明确当前是 record revision 粒度而非逐段严格归因。
- 相关简报只在有引用时展示；“故事变化”默认折叠且只列实质变化；完整快照、ID、算法版本和无变化复核汇总位于二次折叠的“技术与识别审计”。
- “在星域查看”会切换到故事模式，绘制该故事当前修订的完整关系航迹，而不是只高亮首个事件。

### 播放列表中的简报

- 简报不再是一级页面；在播放列表左栏通过“记录 / 简报”切换。记录显示本周期视频列表，简报显示本周期正文；右栏始终保留播放器与转写，不增加第三列。
- 简报正文按安全的 Markdown 语义渲染，支持标题、强调、有序与无序列表、表格、链接和显式换行；未允许的原始 HTML 继续按文本显示。
- 简报保留生成时采用的星域快照和生成口径，并通过结构化引用定位真实事件与证据。
- 点击正文中的来源引用会保持左栏简报与阅读位置，并在右栏定位、播放对应视频和转写；简报模式会在播放控制与转写之间补充当前引用的视频标题、媒体头像、媒体名称、内容时间和原始链接，记录模式则依赖左侧高亮记录而不重复显示。对象引用仍可回到对应星域对象。旧简报未建立结构化引用时仍可按原 Markdown 阅读，不伪造引用。
- 自动简报周期、域提示词与批量生成统一放在独立的“观测域设置”页。一个观测域只有一种简报周期，批量生成只能使用该周期。

### 播放列表

- 播放列表是当前观测域的来源复盘与简报阅读工作台，不请求事件审核或星域分析数据。选中一个周期时并行读取该周期已具备播放资产的来源记录与简报，切换“记录 / 简报”只改变左栏显示，不重复切换时间口径。
- 桌面端约 38% / 62% 双栏：左栏显示本期记录或本期简报，右栏始终显示播放器与转写。视频画面本身支持单击播放/暂停，并与底部播放按钮共享状态。底部固定 64px 周期导航按观测域的 `brief_granularity` 生成日、周或月卡片，点击卡片同时切换视频集合和简报。
- 日期与记录选择可由 URL 恢复和分享；最近日期、记录与播放位置按观测域保存到浏览器本地。首次进入或切换日期时可以恢复记录，但不会自动发声。
- 提供视频/音频播放、上一条/下一条、前后 15 秒、播放速度、自动连播、转写版本、错误状态、重新下载和原始链接。播放器偏好放在播放器内，不提供旧业务设置齿轮。
- 单个周期沿用 500 条上限，达到上限时显示截断提示；时间始终使用内容时间和当前观测域配置的粒度。

### 资料库

- “信源 / 来源记录”是同一资料库的两个标签，默认限定当前观测域，也可显式切换到全局范围。
- 当前域信源范围支持从全部资料搜索并加入已有信源，也支持输入 URL 在同一事务中完成全局查重/创建与加入当前域；行级操作明确为“从当前观测域移除”，不会删除共享信源、来源记录或资产。
- 全局范围保留导入、导出、同步、状态与永久删除；影响全局 `Media` 的开关标注为“全局监控”，永久删除只在全部资料的危险操作中出现。
- 来源记录保留筛选、播放器、转写、笔记与资产状态。当前观测域通过接口的 `domain_id` 作为隐式基础范围，不把域内全部信源回填成“已选媒体”；媒体控件只显示用户主动追加的子集筛选。
- 来源记录筛选区使用单行紧凑工具栏：媒体以可搜索勾选面板呈现，关闭时只显示“全部媒体（数量）”、单个名称或“已选 N 个媒体”；状态使用中文业务文案，常用时间范围与自定义起止时间收进同一个时间控件，避免筛选项数量改变页面高度。
- 来源记录可以反查它参与的 canonical、故事关系与简报引用；证据详情可返回原视频、字符区间及可验证的精确播放位置。

### 运行中心

- 汇总任务、worker、处理覆盖率和失败/跳过原因；运维指标不再占据所有认知页面的固定顶栏。
- 从星域异常或顶部健康入口进入时保存来源页面与观测域上下文，返回后恢复原深链接中的模式、对象、筛选和快照位置。
- 当前域数据维护区承接事件补齐、全部重新抽取、停止相关任务和构建星域；这些命令不再出现在播放列表设置中。
- 继续提供活动任务、已完成任务、类型与时间筛选、实时刷新、错误详情、取消和重试等原任务页能力。活动与历史任务行左侧使用本地内联 SVG 小图标区分视频处理、播放列表/星图、简报、媒体同步和事件处理任务；图标颜色表达任务域，运行状态仍只由右侧状态标签表达。
- V2 改造不要求暂停现有任务，不自动取消或删除队列任务，也不删除历史来源记录和视频资产。

### 资源用量

- “资源用量”是运行中心之后的独立全局“资源观测站”。页头显示 `Asia/Shanghai` 统计口径、生成时间、7 / 30 / 90 天范围切换和手动刷新，默认展示 90 天；切换范围只更新该页，不影响观测域、星域时间窗或任务筛选。
- 桌面首屏采用紧凑的单屏观测舱：视频、外部调用、LLM Token、逻辑资产、数据库与“大小未知资产”六项指标等权排列；“大小未知资产”只表示 `Asset.size_bytes` 尚未记录，不代表文件丢失或不可用。三段信号轨道紧随其后，明确区分调用遥测、资源快照和未接入的主机磁盘，不以单项指标占据主视觉。
- 当前摘要展示具有视频资产的去重视频数、所选窗口真实成功下载次数、外部服务调用、LLM token、逻辑资产大小与数据库规模。已下载视频库存、逻辑资产和数据库摘要在请求时实时查询；来源记录发现或批量迁移不计入下载量。
- 趋势区分别展示每日真实视频下载次数、外部服务调用、LLM 输入 / 输出 token，以及逻辑资产与数据库规模。视频下载只统计成功结束且没有 `skipped/rescheduled` 结果的 `video.download*` 任务，按任务 `finished_at` 归日；强制重新下载成功也计为一次下载。视频图在 7 / 30 / 90 天窗口均展示每日原值，不再用移动均值掩盖真实吞吐，视觉上继续使用低透明度面积折线而非实心柱。外部服务图只画 LLM、ASR、Embedding 三条分类线，不叠加与主要分类高度重合的合计线，并在 90 天窗口显示 7 日移动均值、30 天窗口显示 3 日移动均值、7 天窗口保留每日原值；不统计浏览器或站内 HTTP。逻辑资产使用 `Asset.size_bytes` 已知值，数据库仅在 PostgreSQL 下使用 `pg_database_size`。
- LLM 趋势合并实时采集与一次性历史回填；ASR 同时合并可由请求事件核验的历史调用与实时采集。历史行以 `legacy.*` 操作明确区分，旧结果未保存耗时时显示“历史未记录”；事件日志产生前、无法证明是否真正发起请求的旧 ASR 任务不按任务数推算，Embedding 和资源快照仍从采集功能启用后开始形成。LLM、ASR、Embedding 分别按自己的首条记录确定采集起点，某类服务尚未开始采集时显示断点或隐藏图例，不因其他服务已有数据而补成 `0`；缺失 token usage 与非 PostgreSQL 数据库同样显示断点或“暂无采样”。当天日桶明确可能仍在采样。
- 页面同时显示调用采集与资源快照的开始时间、最近采样时间。主机物理磁盘容量尚无可靠部署侧来源，因此固定显示“未接入部署侧指标”，不把逻辑资产与数据库规模相加后伪装成磁盘占用率。
- 服务调用明细按服务、操作、provider 和 model 展示调用、成功 / 失败、token、累计耗时与最近调用；逻辑资产明细按 `Asset.type` 展示数量、已知大小和缺少 `size_bytes` 的数量。
- 宽屏趋势区使用等权 2×2 网格，外部调用、Token、视频下载与逻辑容量共享相同视觉层级；图表区主动压缩高度，把更多首屏空间留给摘要、链路状态和底部明细。服务画像与资产构成固定在同一首屏网格内，并优先获得足以查看多行记录的高度；内容继续超出时只在面板内部滚动。较窄屏幕恢复页面滚动以避免压缩可读性。图标使用本地内联 SVG，不依赖外部 CDN 或易失效的字体连字。

### 当前观测域设置

- “观测域设置”是“资料库”正下方的独立一级页面；观测域切换二级页只负责返回、搜索、选择、浏览全部和新建，不再把设置藏在列表底部，也不使用设置弹层或抽屉。故事页切换前先取得目标阅读队列，失败时保留原域和原阅读位置；其他域内页面先验证目标入口，提交后发生次级读取错误时保持目标域和选择页并明确报错。
- 应用顶栏下方的侧栏观测域区与域内页面上下文栏共用固定 `64px` 高度和同一边框基线；故事页的“故事更新”上下文栏横跨阅读队列与正文，进入或退出侧栏二级页不得改变这条基线。
- 页面展示“可分析转写 / 当前口径抽取 / 星域收录 / 证据核验”四项处理与产出覆盖，并提供持续观测开关。各项分母独立，不再命名为同一条流水线的“整体分析进度”。当前口径抽取额外展示版本与模型，并拆分有事件、成功但零事件、仅旧口径成功、当前口径失败、尚无成功记录和缺少转写。停用后仍同步和归档匹配的原视频、字幕与转写，但不再投递转写润色、事件抽取、简报和星域更新；同一来源若还属于其他已启用观测域，共享分析仍只执行一次并可被该域复用。已经运行的任务正常结束，重新启用时投递事件补齐和星域刷新。
- 页面先从已加载的观测域目录渲染名称、说明、图片和开关，再通过同一个观测状态请求读取覆盖率、简报周期和提示词；不请求昂贵的播放列表详情。删除影响只在展开危险操作后读取，因此慢聚合不会阻塞页面首屏。
- 删除前读取信源关联、简报、快照、变化、故事、观察状态与活跃任务影响，要求输入完整域名。存在活跃域任务时服务端返回 `409`，不会自动取消任务；共享信源、来源记录和资产明确保留。
- 旧 `main / analysis / settings` 综合子视图不再作为 V2 路由结构；星域和来源播放拥有独立模板、状态与加载生命周期。

- 目录页右上角“管理信源”属于全局入口，固定进入资料库的“信源 / 全部资料”范围；从播放列表或观测域设置进入资料库时仍保留当前观测域范围。

### 事件语义星域实现细节

- 页面功能名称为“事件语义星域”，不再提供“时间演化”或“变化点”tab。主视图默认是三维语义星域，X/Y/Z 都来自固定语义投影，时间不作为 Z 轴。
- 星点是可点选的 canonical 真实事件：单击只在原镜头下选中该点，以白芯金环和带引线的标题标签标明位置，并在右侧展开关联视频、记录、实体、故事与证据详情；右侧“定位”才会移动镜头。直接点击主题标签会选中主题、打开右侧详情，并在当前窗口中保留成员的语义颜色、加亮和绘制细金边；其他事件降至约 22% 的上下文权重。再次点击同一标签或关闭主题条件即可恢复。直接点击不会改变旋转、缩放或平移；只有搜索结果中的主题会主动聚焦对应语义区域。已选主题标签跨语义层级保留显示。
- 星域状态、事件处理任务、覆盖计数、三维语义说明和时间/类型/镜头控制共用同一个响应式工具栏；事件处理任务紧邻主状态显示为紧凑 pill，不独占横向提示条。桌面工具栏固定为“状态摘要 + 操作控件”单行，右侧操作按内容宽度占位，左侧说明在空间不足时截断；仅在小于 64rem 的窄屏回到两条紧凑带，状态徽标与数值不拆成竖排。
- 画布占满主体。首次进入快照时使用稳定的全局主视角，沿既有观察方向把相机距离收至旧全局远景的 70%，使主体星云默认放大约 1.43 倍并占据画布大部分高度，同时保留左右视频卡侧带和底部图例；双击空白区域也回到这一主视角。兼容的观察游标若在首帧前已经返回则直接恢复；首帧显示后不再因预览点、完整点集或标签到达而自动移动镜头。“适配”按当前时间窗口内的活动事件边界重新取景，并采用更紧凑的透视距离。桌面端打开右侧主题、事件详情或“星域变化”时，WebGL 画布按侧栏真实宽度缩进，“适配”以剩余可见画布为中心；窄屏继续使用覆盖式侧栏，避免画布被挤至不可用。星域只保留三维透视相机，支持左键旋转、滚轮或双指缩放、右键或修饰键平移，不提供缺少独立分析语义的平面正交模式。相机状态只有在取景版本、快照、时间窗口和视口比例均兼容且能在首帧前取得时才恢复；本次主视角升级会让旧版远景游标失效一次，之后继续正常保存和恢复用户视角。
- 主画面直接渲染当前窗口内的真实事件点，不再叠加大尺寸光晕、模糊星云或 bloom。点的局部疏密表达事件聚集程度；没有装饰性星点、旋臂、数字聚合圆圈、全图实体连线或全期参照。点云背景由两层低透明度网格组成：远场“坐标穹幕”跟随镜头位置但保持世界方向，因此任意旋转、平移和缩放后仍有连续空间参照，进入事件近景时自动降低存在感；近场“语义引力膜”固定在星域坐标中。首屏直接采用 compact manifest 的最终主题几何，并在点集与标签补齐期间冻结，因此完整 scene 与 metadata 的返回顺序不会改变背景；加载完成后的时间窗交互再按当前窗口内一级星域密度平滑更新曲率。两层均无刻度、不可交互，不改变事件坐标，也不参与筛选、点选或计数。
- 语义缩放分为一级星域、二级主题和真实事件近景。远景最多显示 20–28 个一级标签，中景最多 50–80 个二级标签，近景最多显示 24 个当前窗口主题代表事件标题；标签来自结构化实体、事件类型和中心代表事件，并执行屏幕碰撞消解与边缘避让。普通标签使用略微弱化的语义色文字、透明背景和暗色文字光晕，不显示常驻边框；未选择对象时保持完整可读性。选中主题或真实事件后，标签按“选中对象、同主题成员、父子直接关系、同级上下文、无关对象”逐级降至 100%、82%、62%、54% 和 34% 不透明度；悬停或键盘聚焦时临时恢复完整亮度、深色承托和语义色细描边，已选标签继续使用金色卡片强调。拖动时间轴时，标签和星图使用同一个预览窗口，取消拖动后恢复已提交窗口；标签宽度由浏览器实际排版结果测量，桌面端最长 460px，并随画布变窄而收缩。
- 查找与筛选明确分开：查找是一次性定位命令，关闭后不留下伪条件；筛选只包含事件类型与实体，并以按钮数字显示持续条件数。主题点选属于高亮与检查，不写入筛选条件，也不再生成额外“当前条件”横栏。六对象说明和当前窗口实体排行位于筛选临时面板。右侧详情只在选中主题或事件后打开：一级星域列出当前窗口的二级主题，二级主题列出当前窗口最多 20 个代表事件，选中事件再展开关联视频、记录、实体角色、证据和故事关系等结构化分区；不再围绕事件生成卫星节点。
- 当前窗口事件按八个稳定语义族着色：宏观与政策、市场与资产、公司与资本动作、产业与供给链、科技与网络安全、地缘/法律/监管、消费与社会、其他；底部图例解释颜色。金色表示选中事件，绿色表示实体筛选命中，紫色或青色短程曲线只表示有证据的故事关系。
- 地图提示优先展示事件标题、发生时间和类型；canonical UUID 只作为可复制的技术信息，不作为地图主 Tooltip。
- 底部只有一条基于 `event_time` 的月度时间轴。柱高表示覆盖该月的事件记录，轨道按可用宽度自适应显示月 / 年刻度；绿色窗口可整体拖动，点击任意月将其设为窗口结束月。正常 / 全量只决定可浏览的数据域，不是第二个时间范围。
- 地图只由一个观察窗口驱动，普通进入默认以今天结束并覆盖最近 12 个自然月。窗口主体按月移动，两侧手柄只允许 3/6/9/12 个月宽度；顶部不再重复提供截止日期和月份按钮。播放按 1,000 ms/月整体移动窗口，到末尾自动停止；粒子 shader 直接依据每个事件的时间区间裁剪，提交窗口时在原坐标执行约 220 ms 交叉淡化。拖动时间轴时 GPU 实时预览对应窗口，不产生轨迹、残影或镜头漂移；播放期间不请求实体排行。
- 当前窗口内的点按距窗口结束日的时间衰减：最近 30 天保持完整不透明度，接近 12 个月逐步降至 22% 的可辨识下限。状态优先级为“选中事件 > 主题成员 > 今日/本周焦点 > 普通时间衰减”；选中主题时，主题内的时间焦点保持完整强调，主题外焦点只保留较弱提示，避免时间高亮覆盖主题交互。
- 窗口包含今天时显示“今日事件 / 本周事件”。焦点先按固定快照中 canonical 的发生日选择 `second/day` 精度事件，再叠加观察窗口与当前类型、实体和主题条件；视频发布时间不参与事件归日，月、年或未知精度的模糊事件不会在整段区间内每天冒充当日事件。星图突出全部精确匹配事件；其中有可播放来源的事件按跨媒体/跨视频佐证、成员数和时间可靠性排序，最多选入十个事件，同一媒体最多选择两个不同视频。这表示可审计的证据强度，不声称是尚未在快照中物化的市场影响重要度。达到媒体上限的事件仍在星图中高亮，只是不生成视频卡；某事件有多个关联视频时优先选择当前占位更少的媒体。每个事件只选择自己的一个关联视频，前端再以 `video_id` 合并卡片：同一视频关联多个入选事件时只显示一张卡，并从所有可见事件星点分别连向该卡；卡片位置以这些事件的屏幕投影中心参与侧带布局，标题保留最高排序事件并标明关联事件数。卡片底部直接显示媒体图标、媒体名与视频标题，不再显示“关联视频”前缀或重复视频日期。折叠卡完整落在画布左右各约 36% 的内缩侧带中，距物理边缘至少 56px，中央约 28% 只保留星云、标签和事件点；卡片不固定贴边，而是在侧带内随关联事件投影移动、做二维碰撞消解，并以 1.25px 的浅黄色圆点 SVG 引导线连接各自星点。悬停或键盘聚焦卡片时强化其全部关联线并弱化其他连线；播放固定态使用更饱和、稍密且仍为圆点的金黄色线，不使用持续流动动画。桌面细指针设备停留 180ms 后在原位放大并静音自动预览，移出 220ms 后自动收起；点击则固定卡片、解除静音并继续播放，再次点击收起。展开前会冻结全部卡片的可见位置：左侧卡保留右边界向左扩展，右侧卡保留左边界向右扩展，原鼠标命中区域始终包含在展开卡内，其他卡片不参与二次碰撞排版，避免展开位移触发反复移入移出。触屏设备不启用悬停逻辑。开始拖动或缩放星域时立即暂停并恢复小卡片，同一时刻只播放一张。主题内空结果不跨主题或用其他日期事件补位。
- 时间精度按区间解释：second/day 使用具体日期，month 覆盖整月，year 覆盖整年。页面不以 `available_at` 定位事件。
- 顶部区分 embedding 覆盖、未入地图和失败；已有 ready snapshot 时，后台构建明确显示为“星域后台更新中”，并说明当前星域仍可浏览、系统正在生成下一版快照，不再使用容易被理解为页面未加载完成的“地图构建中”。当前域名称只保留在全局标题和观测域导航中，不在星域工具栏重复显示。
- 星域页可见期间使用单飞的 compact manifest 轮询感知后台更新：构建或回填活跃时每 1.8 秒检查，idle 或请求错误时每 10 秒检查。今日/本周事件焦点使用独立的至少 15 秒节流，不跟随 1.8 秒 manifest 轮询重复执行两次聚合查询；筛选、主题、窗口或快照改变时立即使旧响应失权，再防抖请求新口径。浏览器页面隐藏后暂停 timer 并取消在途请求，重新可见时立即检查一次；离开星域、切换观测域或销毁页面时清理 timer、请求和 `visibilitychange` 监听。
- compact 轮询只在 `snapshot_id` 变化、本地 scene 缺失、点集未完整或标签元数据未完成时恢复对应阶段。首次进入时，客户端优先从 URL 或本地上次选择恢复观测域，立即预热本地 Three.js 并请求 compact manifest；没有可恢复域时只增加一次轻量 `/domains?compact=true` 身份查询，完整域目录、健康检查、资源通道探测、PWA 更新、播放列表详情、观察游标和媒体选项均不阻塞首帧。轻量域解析与系统检查并行，域一确定即启动星图；完整域目录、统计、媒体选项与 PWA 初始化进一步延后到完整点集和标签元数据补齐后，避免同视觉加载序列争用数据库与网络。本地恢复的域会在延后返回的完整目录中复核，已删除时清理旧对象请求并切到有效默认域。compact manifest 返回全局坐标边界、已物化的默认时间窗、语义色和轻量主题几何后，页面立即用空点 scene 创建正式 WebGL controller，先提交最终坐标穹幕与语义引力膜的首帧。该帧可见后才请求最多 4,096 个按全图均匀抽取的真实预览点，原位替换空点几何并依次显现；预览点落下后才并行请求完整 scene 和无覆盖率主题元数据。完整 scene 等待期间，预览点按约 4.6 秒的节奏继续依次点亮，已显现点上循环经过一层低强度青色流光，远场坐标穹幕同步缓慢扫描；这只是持续反馈，不表达伪造百分比。完整点集到达后扫描立即停止，并自然接续最终点集显现与标签收清；系统“减少动态效果”开启时保持静态预览。整个过程保持同一 renderer、canvas、网格和首帧镜头；首次镜头不播放固定飞行动画，预览、完整点集或标签到达也不再自动适配，真实点与标签才承担加载动效。语义网格在两项后台补齐都完成前保持 compact 形态，避免响应先后顺序造成突然变形。完整点集与标签元数据分别管理请求生命周期，任一失败时另一份成功数据仍会应用，后续 compact 轮询恢复未完成阶段，必要时取消同轮悬挂请求后重新补齐。预览阶段禁止点选；搜索定位、变化卡定位、实体索引与对象深链等待完整 scene，主题深链另外等待完整标签元数据，避免把预览响应的重编号当作快照 `point_index`。完整点集显现且主题元数据就绪后，标签才从模糊状态收清。页面不绘制独立 CSS 占位网格，也不显示文字步骤或百分比进度条。覆盖计数与实体排行在完整点集可交互后异步加载。后台快照更新继续保留旧地图，直到新 scene、完整主题元数据和隐藏 mount 首帧都准备完成才原位替换，不重播首次进入动画；同一域与显式快照的重复启动请求单飞共享，迟到响应通过 playlist、snapshot、request token、selection generation 和 lifecycle generation 校验丢弃。跨快照变化卡会把 compact 状态、scene、controller 与 URL 作为同一个选择意图原子提交；历史快照在隐藏 mount 准备期间继续保留当前预览的完整点集与标签补齐任务，只有历史快照成功原子提交后才中断它们，失权请求不会让当前预览永久停在半成品。下载期间的新选择会立即中止隐藏快照的 scene 与标签请求并恢复原 URL，不等待旧下载自然结束；“返回当前星域”使用未固定 `snapshot_id` 的 latest 请求，若用户继续操作原历史星图则对称取消并恢复历史 URL。
- 从简报、变化流或分享链接进入显式历史 `snapshot_id` 时，页面固定该快照并停止当前版本轮询；manifest、主题、故事航迹和主题简报引用共用同一版本。顶部明确显示历史状态并提供“返回当前星域”，历史版本不可用时不静默回退。这里停止的仅是浏览器刷新计时器，不影响后台任务执行。
- 从星域变化打开对象时，检查器直接展示这一次变化的 before/after 摘要；retire 对象自动进入最后仍包含它的历史快照。只有新增且带证据的显式 `corrects` 关系显示为“有证据的纠正”。
- 证据检查器展示 verified 状态、字符区间或精确播放位置、片段 SHA-256 与 transcript asset 版本状态；当前转写已更新时保留冻结证据并明确提示，不静默重映射字符区间。
- 页面使用本地固定版本 Three.js 和 WebGL2；不支持 WebGL2 或 context 无法恢复时显示明确错误。静止时停止动画帧；10 万点以上场景首帧像素比上限为 1.25，其余场景为 1.5，持续低帧率时降至 1，不删减事件或改变坐标。离开星域时释放 renderer、材质、render target、observer 和事件监听。
- 播放列表作为同一内容来源集合，不按媒体来源切分或加权。来源权重是明确延后项，不在 UI 中伪装为可调参数。
- 抽取、全量重抽、停止任务和地图重建集中在运行中心的当前域数据维护区。

## 当前交互特点

- 大多数写操作都会给出 toast，并可跳转到任务页查看异步执行结果。
- 任务页和概览页依赖 `/api/ws/jobs` 与 `/api/ws/job_stats` 做实时刷新。
- 概览页首屏依赖 `/api/stats`；其他页面启动时不等待 `/api/stats` 完成，统计信息允许延后静默刷新。
- 资源用量页仅在进入 `/usage`、切换 7 / 30 / 90 天范围或用户手动刷新时请求 `/api/usage`；离开页面会释放图表实例，不把用量查询加入星域首屏关键路径。
- 简报支持复制文本、打开原文、重新生成当前周期，以及按粒度和日期范围批量生成。
- 设置页以运行时配置为主，保存后通常无需重启服务。

## 当前 UI 边界

- UI 仍以单用户桌面 / 平板场景为主，移动端重点保障浏览、播放和 PWA 安装路径。
- 全局搜索当前采用关系字段与文本匹配，不伪装为向量语义召回；构建侧 embedding 查询优化见 V2 能力差距文档。
- 智能体接入页面是前端说明页，不等价于 MCP 实际 endpoint；真实接口由主 API 进程挂载在 `/mcp` 提供。
- 播放日期、记录和位置当前保存在 URL 与本机浏览器中；跨设备播放游标尚未实现。
