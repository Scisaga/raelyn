# Raelyn V2 核心界面线框规范

## 文档职责

本文定义 V2 核心界面的空间关系、信息优先级和交互节奏，是后续高保真设计与前端实现的验收依据。

- 产品意图见 [V2 产品愿景](../vision.md)。
- 页面与对象关系见 [V2 信息架构](../product/information-architecture-v2.md)。
- 当前实现差距见 [V2 现状能力差距](../product/capability-gap-v2.md)。

现有 [首页 SVG](wireframes/home-v2.svg) 与 [星图 SVG](wireframes/event-map-v2.svg) 是上一轮信息架构的布局草图，只保留为演进记录。它们把星图缩成首页卡片、把变化与简报堆成仪表盘区块，不再作为 V2 目标稿。后续视觉重绘必须以本文为准。

## 核心设计判断

1. 星域观测台就是首页，不再额外设计一个卡片化“今日观察”仪表盘；
2. 星域在桌面首屏占据绝对主视觉，变化、故事、简报和证据以图层与检查器协作；
3. 时间播放要让星域密度变化可感知，而不改变语义坐标或制造虚构轨迹；
4. 点开任何对象后，理解与证据在原空间展开，不把用户立即抛到另一个孤立页面；
5. 故事拥有独立深度阅读界面，但从星域进入并能返回相同空间位置；
6. 当前观测域的来源播放保留为独立工作台，以按域配置生成的周期导航、记录/简报左栏和播放器形成连续复盘闭环；
7. 信源和来源记录保留完整管理能力，但视觉上明确属于观测站的资料层；
8. 播放、观测域、简报和数据维护的设置按职责分开，不恢复旧播放列表的综合设置子视图；
9. 资源用量作为运行中心之后的独立系统页展示当前规模与真实采集趋势，不把库存卡片重新放回星域首页，也不伪造尚未采集的历史数据。

### 布局规则

- 侧栏正常态保持紧凑，当前观测域始终高于页面导航；展开态显示真实头像、当前域名和进入箭头，折叠态保留可聚焦的头像；
- 点击当前观测域后，品牌栏以下整体切换为侧栏二级页：`返回 → 搜索 → 可滚动域列表 → 浏览全部 / 新建`。二级页替换一级导航，不覆盖主内容、不使用原生下拉框或浮层；无头像时才显示名称首字；
- 应用顶栏下方的观测域区与页面上下文栏统一为 `64px` 固定高度并共用边框基线；故事页上下文栏横跨队列和阅读区；
- 主内容贴边、全高，不在外层再包大圆角卡片；
- 顶栏只承载当前观察上下文，不常驻队列与基础设施计数；
- 系统异常通过一个状态入口出现，点击后携带当前域和受影响对象进入运行中心；
- 资源用量固定在运行中心之后，作为全局系统页面，不继承当前观测域筛选；
- 资料库默认继承当前域筛选，但在页面内可切换为全局。

### 区域职责

| 区域 | 职责 | 视觉优先级 |
| --- | --- | --- |
| 星域画布 | 展示当前窗口内真实事件、主题结构和选择状态 | 最高，占主要视口 |
| 时间焦点 | 按事件发生日突出今日或本周的全部精确日期事件，并将其中最多十个有可播放来源的视频卡片投影到左右内缩侧带；同一媒体最多两张，以有限短线连接真实事件点，中央主体星云不放置折叠卡 | 高，但不切换对象空间 |
| 星域变化 | 解释自上次观察以来的变化 | 中，默认收起，按需覆盖 |
| 时间轴 | 控制发生时间窗口与回放 | 高，始终可见 |
| 快速对象条 | 提供当前选择的最短解释与关键操作 | 按需浮现 |
| 查找 | 一次性定位主题、事件和实体，不保留伪条件 | 按需临时覆盖 |
| 筛选 | 持续改变事件类型与实体可见范围，并显示条件数 | 按需临时覆盖 |

### 首次进入

- 普通进入恢复上次观测域，但时间窗口回到“截至今天的 12 个月”；显式历史链接才恢复指定时间窗口、镜头和选择；
- 以克制的变化标记显示“自上次观察以来”新增或更新的对象；
- 星域变化默认收起，以未读徽标提示；故事或证据在选中对应对象时打开检查器；
- 打开后自动选择第一个非空口径，没有未读变化时显示准确空状态，不用空白统计卡长期遮挡星域；
- 没有历史游标时明确使用“最近 24 小时”“当前窗口”等固定口径；
- 没有 ready 星域时进入建立星域的引导状态，并显示真实处理阶段。

### 时间播放

- 点击播放后，固定长度窗口按月或按自适应时间步推进；
- 星点依事件发生区间进入、保持或离开当前窗口；
- 坐标与镜头不随播放改变；
- 点的出现、消失和透明度过渡用于表达密度变化，持续时间建议为 180–260ms；
- 主题标签与密度统计使用同一预览窗口同步更新；
- 故事模式下，航迹随成员进入时间逐段点亮；
- 播放期间可以暂停、拖动、改变速度或选择一个变化；
- 开启减少动态效果时不自动播放，改用离散时间步与变化列表表达同一信息。

### 变化视觉语法

| 变化 | 星域表达 | 星域变化表达 |
| --- | --- | --- |
| 新发生 | 星点按发生时间出现，短暂亮芯 | 事件标题、发生时间、所属主题 |
| 认知变化 | 现有时间位置出现细环，不伪装成刚发生 | 首次入图或修订时间、真实发生时间、变化原因 |
| 故事新增成员 | 航迹延伸到新节点 | 故事标题、新节点和关系类型 |
| 新证据 | 星点或关系出现证据徽记 | 新来源、证据类型和覆盖变化 |
| 纠正 | 星点显示可辨识的修订标记 | 修订前后、依据与时间 |
| merge / split | 只在变化模式显示身份过渡 | 谱系说明，不做粒子爆炸效果 |

任何动画都必须由真实对象变化驱动，不使用装饰星点、随机飞线或无依据的“能量波”。

## 星域对象检查器

选中主题、真实事件、故事或证据后，右侧星域变化切换为对象检查器；关闭后恢复星域变化。

### 行为

- 普通点选不移动镜头；
- 检查器内的“定位”才执行 zoom / focus；
- 打开检查器不重置时间窗口、筛选或播放位置；
- 点击证据在同一检查器中展开上下文，可继续进入来源记录；
- 点击故事点亮航迹，点击简报定位相关段落；
- 技术 ID、snapshot 和模型口径默认折叠到底部。

### 设计要求

- 稳定标题和最后阅读位置跨快照持续，最新进展单独更新；
- 时间线只使用事件发生时间，长故事按年月分隔并完整展示；不画贯穿全部事件的连续线；
- 只有真实关系边才附着在目标事件下，使用“阶段推进 / 因果承接 / 事件响应 / 事实纠正 · 来自「源事件」”，自然支持分支、多个来源和非相邻关系；
- “自上次阅读后”只使用实质变化，打开详情不自动清除，历史模式不提供清除 current 未读的操作；
- 首次阅读从最早事件开始，回访恢复位置，有新增事件时定位首个新增项；同时提供“跳到最新”；
- 事件与关系检查器按需打开；普通路径不暴露技术 ID 和相似度指标，证据不足、未验证、来源版本替换或无精确播放位置必须直说；
- “在星域点亮”返回原观测域、恢复同一时间范围并显示完整航迹。

- 从星域进入简报时自动定位到解释当前对象的段落；
- 引用对象发生 merge / split 或纠正时显示身份变化，不静默跳转到另一事实。

简报周期、提示词和批量生成不出现在播放工作台，统一归入“观测域设置”。底部卡片直接按该域唯一周期生成。

### 布局与行为

- 主体采用约 38% / 62% 双栏，左栏以“记录 / 简报”切换，不保留独立简报页或第三列；
- 顶部工具条固定，列表、简报正文和转写各自滚动，底部 64px 周期导航固定；
- 周期卡片数量与记录列表只统计当前观测域中具备播放资产的来源记录，并统一使用内容时间；
- 选择周期卡片同时加载该周期记录和简报并恢复上次记录，没有历史选择时选中第一条但不自动播放声音；
- URL 保存观测域、模式、周期起点、记录和播放秒数；粒度只读取观测域配置。前往资料库或运行中心后可以回到同一位置；旧 `/briefs` 链接兼容进入简报模式；
- “管理信源”进入资料库的当前域范围；“更多”只提供跨页快捷入口，不打开旧综合设置页。

### 设置去向

```text
当前观测域设置：持续观测 / 处理与产出覆盖 / 名称 / 描述 / 头图 / 简报周期 / 提示词 / 批量生成 / 删除观测域
简报批量生成：按当前域周期选择日期范围 / 投递确认
资料库：加入当前域 / 从当前域移除 / 全局信源管理
运行中心：事件补齐 / 全量重抽 / 停止任务 / 构建星域
播放器内：速度 / 自动连播 / 转写版本
```

删除观测域必须展示域内关联数据影响摘要并要求输入观测域名称。全局删除信源与“从当前观测域移除”不得使用相同图标、文案或确认框。

## 核心线框五：资料库

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 资料库    [当前观测域 ▾]      [信源] [来源记录]    搜索  筛选  [加入信源]│
├─────────────────────────────────────────────────────────────────────────────┤
│ 信源视图：头像 / 名称 / provider / 所属域 / 新鲜度 / 监控 / 同步操作       │
│                                                                             │
│ 来源记录视图：标题 / 内容时间 / 信源 / 转写 / 事件 / 证据 / 处理状态       │
│                                                                             │
│ 点击记录 → 播放器 + 转写 + 资产 + 支撑的事件/故事/简报 + 处理记录          │
└─────────────────────────────────────────────────────────────────────────────┘
```

- 资料库使用一个一级导航与两个主视图，不把信源和来源记录重新拆回多个全局入口；
- 默认显示当前观测域范围，一键切换全部；
- 当前域范围的“加入信源”同时支持选择全部资料中的已有信源和输入 URL 新建；新建与加入必须作为一个完整结果反馈；
- 当前域行级操作是“从当前观测域移除”，全局永久删除只在全部资料的信源详情危险区；
- 来源记录主信息优先表达内容时间、证据关系和处理完整性；
- 下载状态保留但不压过“这条记录支撑了哪些理解”；
- 事件或证据进入来源记录详情时，自动定位相应转写片段。

## 核心线框六：资源用量

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 应用顶部栏：资源用量                                    更新时间 [刷新] │
├──────────────────────────────────────────────────────────────────────────┤
│ 视频库存       │ 累计调用       │ 累计 Token       │ 逻辑资产 │ 数据库  │
├───────────────────────────────────────────────┬──────────────────────────┤
│ 外部调用主图（近90天 / 7日均值）              │ 存储规模                 │
│ LLM / ASR / 向量：日期与读数                  │ 逻辑资产 / 数据库        │
├───────────────────────┬───────────────────────┼──────────────────────────┤
│ Token 消耗            │ 视频下载柱状图        │ 资产构成                 │
│ 每日输入 / 输出       │ 每日成功量            │ 类型 / 数量 / 占比 / 容量│
├───────────────────────┴───────────────────────┴──────────────────────────┤
│ 服务画像（采集以来 / 链路可展开来源）                                   │
│ 调用链路 / 调用次数 / 成功率 / Token / 耗时 / 最近活动                  │
├──────────────────────────────────────────────────────────────────────────┤
│ 最近调用 · 最近快照 · 主机磁盘未接入                  采集信息与统计说明│
└──────────────────────────────────────────────────────────────────────────┘
```

- `/usage` 是系统一级入口，四张趋势图与服务、资产明细默认同时可见；取消周期切换和未知大小资产显示。
- 调用和 Token 是采集以来累计，当前库存、资产、数据库是实时规模；只有趋势及卡片明确标名的“近 90 天下载”使用 90 天窗口，累计值不要求等于窗口趋势之和。
- Token 缺失调用按 0 计，保留全部已知值，信息入口展示精确值和缺失次数。未采集仍为未知，不把缺快照或物理磁盘未接入补为 0。
- 存储图显示“逻辑资产”和“数据库”两条实线；逻辑资产在首次快照前采用现存资产创建日期和已知大小的累计值，之后采用实测快照。回溯值与快照统一为同一条曲线，数据来源及边界放入统计说明，不单列估算图例或图下说明，也不覆盖或写入快照。
- 移除“资源观测站”独立标题行，更新时间和刷新放入应用顶部栏。摘要标题配 18px 线性图标，指标用常规字重等宽数字；背景、边框与低对比表面对齐星域，不使用彩色侧条或图标光晕。五项摘要合为连续指标栏；调用主图占左侧通栏，Token 与下载量位于其下，右侧为存储与资产表格。资产表格不显示重复的顶部构成条或彩色圆点。采集信息压为一行，窄屏指标两列、图区纵向排列并允许滚动。
- 服务链路可展开来源、provider/model 与缺失说明；采集说明保留起止时间、历史迁移来源和上海时区口径。数据库与逻辑资产分别显示，不伪称主机磁盘占用率。
- 实现及统计细则见 [UI 概览](overview.md) 和 [REST API](../api/rest.md)。

## 空状态与异常状态

### 新观测域

星域画布保留为空间主体，中央解释建立过程：

```text
选择信源 → 获取来源记录 → 生成转写 → 抽取事件 → 建立第一版星域
```

每个阶段使用真实状态和下一步操作，不放虚构示例星点冒充数据。

### 数据陈旧

- 在观测域标题旁显示“数据更新停滞”；
- 星域变化顶部说明受影响的时间范围；
- 点击携带域和失败任务进入运行中心；
- 旧 ready 星域继续可浏览，并明确完成时间。

### 星域构建中

- 当前 ready 星域保持可浏览；
- 新版构建只显示轻量状态，不用全屏遮罩；
- 构建完成后提示可切换，并说明是否保持坐标连续；
- rebase 时在切换前解释空间记忆将发生变化。

### 证据不足

- 事件或关系使用明确的证据不足状态；
- 用户仍可查看候选记录，但它不能以普通可信星点样式出现；
- 提供进入待验证或来源记录的操作。

## 响应式折叠

### 平板

- 侧栏折叠为图标栏或抽屉；
- 星域变化、查找、筛选和对象检查器互斥覆盖；
- 时间轴保持底部全宽；
- 故事与简报采用主内容 + 覆盖检查器。
- 播放列表改为播放器在上、记录或简报在下，底部周期导航保持固定，转写以覆盖面板展开。
- 资源用量摘要改为两至三列，趋势图改单列排列；服务与资产明细保持横向滚动表格。

### 手机

- 星域默认全屏；
- 顶部只保留观测域、模式和一个综合操作入口；
- 时间轴支持播放、暂停、拖动和步进；
- 星域变化、查找、筛选、对象详情和简报使用底部抽屉；
- 完整事件列表作为非空间视图，覆盖所有事件与证据能力；
- 不支持 WebGL2 时直接进入事件列表，并保留“星域不可用”的明确说明。
- 播放列表优先展示播放器，记录/简报与转写通过标签或底部抽屉切换，周期导航保持横向滑动和记录数量提示。
- 资源用量摘要使用单列或双列，趋势图单列并固定最近 90 天；刷新始终可从顶部栏触达，明细允许横向滚动而不压缩数值。

## 动效与无障碍

- 动效只表达对象进入、状态变化、故事延伸和镜头操作；
- 普通浏览时不持续自动旋转；
- 用户操作立即中止自动镜头与播放；
- `prefers-reduced-motion` 下关闭自动播放、持续旋转和粒子入场；
- 用列表、标签和差异文本完整表达动画中的变化；
- 颜色编码同时提供形状、边框或文字状态；
- 星点不可逐个 tab 遍历时，键盘用户通过搜索、主题列表和事件列表访问同一对象；
- 焦点进入检查器后遵循可预测的焦点顺序，关闭时返回触发对象。

## 视觉验收底线

- 星域在首页中是主空间，不是缩略图卡片；
- 页面不再出现媒体数、视频数、任务成功数和存储占用组成的首屏仪表盘；
- 星域变化不会永久挤压星域，检查器不会重置观察上下文；
- 时间播放可以明显看出事件密度变化，同时坐标和镜头保持稳定；
- 故事航迹只来自有证据关系；
- 事件、故事与简报可以双向定位到证据；
- 播放列表位于故事下方、资料库上方；按域配置生成的周期导航固定，记录和简报在左栏切换；
- 观测域设置位于资料库下方，使用独立页面承载持续观测、处理与产出覆盖和危险操作；
- 播放列表不再出现事件、星域分析、综合设置子视图或常驻第三列；简报是左栏明确标签；
- 域设置、信源范围、简报配置和数据维护都有唯一且可发现的归属；
- 资料库完整承接信源和来源记录管理，但在导航中处于支撑位置；
- 资源用量位于运行中心之后，当前值、历史快照、采集缺口和未接入物理磁盘拥有明确且不同的视觉状态；
- 不使用装饰星点、虚构飞线、bloom 星云、无依据热点或伪变化动画。
