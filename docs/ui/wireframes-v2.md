# Raelyn V2 核心界面线框规范

## 文档职责

本文定义 V2 核心界面的空间关系、信息优先级和交互节奏，是后续高保真设计与前端实现的验收依据。

- 产品意图见 [V2 产品愿景](../vision.md)。
- 页面与对象关系见 [V2 信息架构](../product/information-architecture-v2.md)。
- 当前实现差距见 [V2 现状能力差距](../product/capability-gap-v2.md)。

现有 [首页 SVG](wireframes/home-v2.svg) 与 [星图 SVG](wireframes/event-map-v2.svg) 是上一轮信息架构的布局草图，只保留为演进记录。它们把星图缩成首页卡片、把变化与简报堆成仪表盘区块，不再作为 V2 目标稿。后续视觉重绘必须以本文为准。

## 核心设计判断

1. 星域观测台就是首页，不再额外设计一个卡片化“今日观察”仪表盘；
2. 星域在桌面首屏占据绝对主视觉，变化、故事、简报和证据以图层与检查器协作；
3. 时间播放要让星域密度变化可感知，而不改变语义坐标或制造虚构轨迹；
4. 点开任何对象后，理解与证据在原空间展开，不把用户立即抛到另一个孤立页面；
5. 故事拥有独立深度阅读界面，但从星域进入并能返回相同空间位置；
6. 当前观测域的来源播放保留为独立工作台，以按日日历、记录列表和播放器形成连续复盘闭环；
7. 信源和来源记录保留完整管理能力，但视觉上明确属于观测站的资料层；
8. 播放、观测域、简报和数据维护的设置按职责分开，不恢复旧播放列表的综合设置子视图。

### 布局规则

- 侧栏展开宽度保持紧凑，观测域切换器始终高于页面导航；
- 当前观测域名称负责切换范围，旁边的明确设置按钮进入当前域设置；不使用播放列表齿轮承载域设置；
- 主内容贴边、全高，不在外层再包大圆角卡片；
- 顶栏只承载当前观察上下文，不常驻队列与基础设施计数；
- 系统异常通过一个状态入口出现，点击后携带当前域和受影响对象进入运行中心；
- 资料库默认继承当前域筛选，但在页面内可切换为全局。

### 区域职责

| 区域 | 职责 | 视觉优先级 |
| --- | --- | --- |
| 星域画布 | 展示当前窗口内真实事件、主题结构和选择状态 | 最高，占主要视口 |
| 观察模式 | 在现在、回放、故事和验证之间切换解释方式 | 高，但不切换对象空间 |
| 星域变化 | 解释自上次观察以来的变化 | 中，默认收起，按需覆盖 |
| 时间轴 | 控制发生时间窗口与回放 | 高，始终可见 |
| 快速对象条 | 提供当前选择的最短解释与关键操作 | 按需浮现 |
| 搜索与筛选 | 定位主题、事件、实体和故事 | 按需展开 |

### 首次进入

- 有历史观察状态时恢复上次观测域、时间窗口、镜头和选择；
- 以克制的变化标记显示“自上次观察以来”新增或更新的对象；
- “现在/回放”模式下星域变化默认收起，以未读徽标提示；故事/验证模式按任务主动打开；
- 打开后自动选择第一个非空口径，没有未读变化时显示准确空状态，不用空白统计卡长期遮挡星域；
- 没有历史游标时明确使用“最近 24 小时”“当前窗口”等固定口径；
- 没有 ready 星域时进入建立星域的引导状态，并显示真实处理阶段。

### 时间播放

- 点击播放后，固定长度窗口按月或按自适应时间步推进；
- 星点依事件发生区间进入、保持或离开当前窗口；
- 坐标与镜头不随播放改变；
- 点的出现、消失和透明度过渡用于表达密度变化，持续时间建议为 180–260ms；
- 主题标签与密度统计使用同一预览窗口同步更新；
- 故事模式下，航迹随成员进入时间逐段点亮；
- 播放期间可以暂停、拖动、改变速度或选择一个变化；
- 开启减少动态效果时不自动播放，改用离散时间步与变化列表表达同一信息。

### 变化视觉语法

| 变化 | 星域表达 | 星域变化表达 |
| --- | --- | --- |
| 新发生 | 星点按发生时间出现，短暂亮芯 | 事件标题、发生时间、所属主题 |
| 认知变化 | 现有时间位置出现细环，不伪装成刚发生 | 首次入图或修订时间、真实发生时间、变化原因 |
| 故事新增成员 | 航迹延伸到新节点 | 故事标题、新节点和关系类型 |
| 新证据 | 星点或关系出现证据徽记 | 新来源、证据类型和覆盖变化 |
| 纠正 | 星点显示可辨识的修订标记 | 修订前后、依据与时间 |
| merge / split | 只在变化模式显示身份过渡 | 谱系说明，不做粒子爆炸效果 |

任何动画都必须由真实对象变化驱动，不使用装饰星点、随机飞线或无依据的“能量波”。

## 星域对象检查器

选中主题、真实事件、故事或证据后，右侧星域变化切换为对象检查器；关闭后恢复星域变化。

```text
┌───────────────────────────────┐
│ 真实事件                 ×    │
│ 美联储维持利率不变             │
│ 发生于 2026-07-25              │
│ 进入星域于 2026-07-26          │
│ [定位] [点亮故事] [打开简报]   │
├───────────────────────────────┤
│ 发生了什么                     │
│ 一段直接、具体的事实摘要       │
├───────────────────────────────┤
│ 本次变化                       │
│ + 2 条事件记录  + 1 条新证据   │
├───────────────────────────────┤
│ 故事 / 主题 / 实体             │
├───────────────────────────────┤
│ 事件记录                       │
│ 来源 A · 来源 B · 来源 C       │
├───────────────────────────────┤
│ 证据                           │
│ “…原文片段…”       [打开原文]  │
├───────────────────────────────┤
│ 身份谱系与技术信息             │
└───────────────────────────────┘
```

### 行为

- 普通点选不移动镜头；
- 检查器内的“定位”才执行 zoom / focus；
- 打开检查器不重置时间窗口、筛选或播放位置；
- 点击证据在同一检查器中展开上下文，可继续进入来源记录；
- 点击故事点亮航迹，点击简报定位相关段落；
- 技术 ID、snapshot 和模型口径默认折叠到底部。

### 设计要求

- 故事标题、身份和最后阅读位置跨快照持续；
- 时间线只使用事件发生时间；
- 每条边显示 relation type 与证据，不使用无解释连线；
- “本次新增”以用户观察游标为基线；
- 事件节点、故事摘要和证据检查器互相定位；
- “在星域点亮”返回原观测域、恢复同一时间范围并显示完整航迹。

## 核心线框三：星域简报

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 2026 年 7 月观测简报    07/01—07/31   快照 07/31   [在星域打开] [复制]   │
├──────────────────────────────────────────────┬──────────────────────────────┤
│ 本期星域概览                                 │ 引用检查器                   │
│ 宏观政策星群明显增密 [事件 12] [主题 3]      │                              │
│                                              │ 当前引用：事件 12            │
│ 主要变化                                     │ 事实摘要                     │
│ …… [故事：全球利率政策转向]                  │ 证据覆盖                     │
│ …… [事件：美联储维持利率不变]                │ 来源 A / B / C                │
│                                              │ [星域定位] [打开证据]        │
│ 新证据与纠正                                 │                              │
│ …… [证据：来源记录 28]                       │                              │
└──────────────────────────────────────────────┴──────────────────────────────┘
```

- 引用是结构化对象，不只是 Markdown 链接文字；
- 点击引用时检查器显示对象，并可在星域中定位；
- “在星域打开”恢复简报对应时间窗口和快照语义；
- 从星域进入简报时自动定位到解释当前对象的段落；
- 引用对象发生 merge / split 或纠正时显示身份变化，不静默跳转到另一事实。

简报顶部提供“生成设置”和“批量生成”两个明确动作。前者编辑自动简报周期和提示词，后者选择粒度与日期范围后投递任务；二者都不改变播放列表日历。

### 布局与行为

- 主体采用约 38% / 62% 双栏，不保留旧版最左侧事件/周期简报栏；
- 顶部工具条固定，列表和转写各自滚动，底部 64px 按日日历固定；
- 日历数量与列表只统计当前观测域中具备播放资产的来源记录，并统一使用内容时间；
- 切换日期加载当天列表并恢复上次记录，没有历史选择时选中第一条但不自动播放声音；
- URL 保存观测域、日期、记录和播放秒数；前往资料库、简报或运行中心后可以回到同一位置；
- “管理信源”进入资料库的当前域范围；“更多”只提供跨页快捷入口，不打开旧综合设置页。

### 设置去向

```text
当前观测域设置：名称 / 描述 / 头像 / 背景 / 删除观测域
简报生成设置：自动简报周期 / 提示词
简报批量生成：粒度 / 日期范围 / 投递确认
资料库：加入当前域 / 从当前域移除 / 全局信源管理
运行中心：事件补齐 / 全量重抽 / 停止任务 / 构建星域
播放器内：速度 / 自动连播 / 转写版本
```

删除观测域必须展示域内关联数据影响摘要并要求输入观测域名称。全局删除信源与“从当前观测域移除”不得使用相同图标、文案或确认框。

## 核心线框五：资料库

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 资料库    [当前观测域 ▾]      [信源] [来源记录]    搜索  筛选  [加入信源]│
├─────────────────────────────────────────────────────────────────────────────┤
│ 信源视图：头像 / 名称 / provider / 所属域 / 新鲜度 / 监控 / 同步操作       │
│                                                                             │
│ 来源记录视图：标题 / 内容时间 / 信源 / 转写 / 事件 / 证据 / 处理状态       │
│                                                                             │
│ 点击记录 → 播放器 + 转写 + 资产 + 支撑的事件/故事/简报 + 处理记录          │
└─────────────────────────────────────────────────────────────────────────────┘
```

- 资料库使用一个一级导航与两个主视图，不把信源和来源记录重新拆回多个全局入口；
- 默认显示当前观测域范围，一键切换全部；
- 当前域范围的“加入信源”同时支持选择全部资料中的已有信源和输入 URL 新建；新建与加入必须作为一个完整结果反馈；
- 当前域行级操作是“从当前观测域移除”，全局永久删除只在全部资料的信源详情危险区；
- 来源记录主信息优先表达内容时间、证据关系和处理完整性；
- 下载状态保留但不压过“这条记录支撑了哪些理解”；
- 事件或证据进入来源记录详情时，自动定位相应转写片段。

## 空状态与异常状态

### 新观测域

星域画布保留为空间主体，中央解释建立过程：

```text
选择信源 → 获取来源记录 → 生成转写 → 抽取事件 → 建立第一版星域
```

每个阶段使用真实状态和下一步操作，不放虚构示例星点冒充数据。

### 数据陈旧

- 在观测域标题旁显示“数据更新停滞”；
- 星域变化顶部说明受影响的时间范围；
- 点击携带域和失败任务进入运行中心；
- 旧 ready 星域继续可浏览，并明确完成时间。

### 星域构建中

- 当前 ready 星域保持可浏览；
- 新版构建只显示轻量状态，不用全屏遮罩；
- 构建完成后提示可切换，并说明是否保持坐标连续；
- rebase 时在切换前解释空间记忆将发生变化。

### 证据不足

- 事件或关系使用明确的证据不足状态；
- 用户仍可查看候选记录，但它不能以普通可信星点样式出现；
- 提供进入待验证或来源记录的操作。

## 响应式折叠

### 平板

- 侧栏折叠为图标栏或抽屉；
- 星域变化、搜索和对象检查器互斥覆盖；
- 时间轴保持底部全宽；
- 故事与简报采用主内容 + 覆盖检查器。
- 播放列表改为播放器在上、记录列表在下，底部按日日历保持固定，转写以覆盖面板展开。

### 手机

- 星域默认全屏；
- 顶部只保留观测域、模式和一个综合操作入口；
- 时间轴支持播放、暂停、拖动和步进；
- 星域变化、搜索、对象详情和简报使用底部抽屉；
- 完整事件列表作为非空间视图，覆盖所有事件与证据能力；
- 不支持 WebGL2 时直接进入事件列表，并保留“星域不可用”的明确说明。
- 播放列表优先展示播放器，记录列表与转写通过标签或底部抽屉切换，日历保持横向滑动和日期数量提示。

## 动效与无障碍

- 动效只表达对象进入、状态变化、故事延伸和镜头操作；
- 普通浏览时不持续自动旋转；
- 用户操作立即中止自动镜头与播放；
- `prefers-reduced-motion` 下关闭自动播放、持续旋转和粒子入场；
- 用列表、标签和差异文本完整表达动画中的变化；
- 颜色编码同时提供形状、边框或文字状态；
- 星点不可逐个 tab 遍历时，键盘用户通过搜索、主题列表和事件列表访问同一对象；
- 焦点进入检查器后遵循可预测的焦点顺序，关闭时返回触发对象。

## 视觉验收底线

- 星域在首页中是主空间，不是缩略图卡片；
- 页面不再出现媒体数、视频数、任务成功数和存储占用组成的首屏仪表盘；
- 星域变化不会永久挤压星域，检查器不会重置观察上下文；
- 时间播放可以明显看出事件密度变化，同时坐标和镜头保持稳定；
- 故事航迹只来自有证据关系；
- 事件、故事与简报可以双向定位到证据；
- 播放列表位于简报下方、资料库上方，按日日历、记录列表和播放器在桌面端同时可见；
- 播放列表不再出现事件、周期简报、星域分析或综合设置子视图；
- 域设置、信源范围、简报配置和数据维护都有唯一且可发现的归属；
- 资料库完整承接信源和来源记录管理，但在导航中处于支撑位置；
- 不使用装饰星点、虚构飞线、bloom 星云、无依据热点或伪变化动画。
