# 风险与处理

## 平台风控 / 限速

- 风险：高频抓取、下载和重试可能触发平台限速或风控
- 处理：内建 provider 级并发门控，并配合重试退避策略

## 大文件与播放

- 风险：若视频内容完全走 API 代理而不支持 `Range`，播放体验会明显变差
- 处理：代理方案必须支持 `Range`；若 MinIO 可直连，优先返回短期有效的 `presigned_url`

## 字幕与语言多样性

- 风险：字幕格式、语言标记、自动字幕质量差异较大
- 处理：语言检测和优先级策略需可配置，默认优先中文

## LLM 输入超限

- 风险：转写文本过长会导致简报生成时超出模型输入上限
- 处理：简报生成必须做 chunking 与摘要合并，并保留来源引用

## 存储膨胀

- 风险：长期保留视频、音频、字幕和转写内容，存储占用会持续增长
- 处理：后续可引入生命周期管理，例如只保留音频 / 文本，或只保留最近 N 天视频
