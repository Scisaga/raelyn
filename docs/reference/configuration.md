# 配置项说明

环境变量（示例）：

- `DATABASE_URL`
- `S3_ENDPOINT`
- `S3_ACCESS_KEY`
- `S3_SECRET_KEY`
- `S3_BUCKET`
- `S3_REGION`
- `S3_USE_SSL`（`true / false`）
- `FFMPEG_PATH`（可选）
- `SYNC_INTERVAL_MINUTES`（默认 `5`）
- `YOUTUBE_DOWNLOAD_CONCURRENCY`
- `BILIBILI_DOWNLOAD_CONCURRENCY`
- `ASR_URL`（可空）
- `LLM_URL`（可空）
- `TIMEZONE`（默认 `Asia/Shanghai` 或由部署决定）

这份文档只负责记录运行配置项，不承载架构设计或 API 约定。
