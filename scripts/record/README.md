# 产品导览录制流水线

把 Raelyn 的产品导览片做成**可重跑的构建产物**，而不是一次性手工录屏。UI 迭代之后
重跑一遍即可，不必重新手动走位、对轴、打字幕。

录制、画面字幕、配音演讲稿、镜头转场和合成全部脚本化，唯一真源是
[`tour.config.mjs`](tour.config.mjs)。

## 快速开始

```bash
cd scripts/record
npm ci && npx playwright install chromium   # 首次；版本由 package-lock.json 锁定

# 应用必须已经在跑（devctl.sh start 或 docker compose up）
../dev/devctl.sh status

node record-tour.mjs --check     # 数据、深链接、快照、选择器与 H.264 巡检
node record-tour.mjs             # 只录原始界面片段，到这里停下来审片

# 审片通过后才执行后处理；先生成画面字幕与配音演讲稿供复审
node make-subtitles.mjs
node make-narration.mjs

# 两套文案通过后再选择音轨并合成；run-all.sh 会从录制开始完整重跑
node select-music.mjs
node compose-tour.mjs
```

`--check` 会先通过真实 API 校验固定快照、两级主题、事件、故事、播放日期和简报，再逐镜头
验证页面确实加载了指定快照以及选择器仍然命中。任一核心对象失效都会在开始抓帧前失败。
审片目录是 `out/shots/`。录制阶段遵循“先录原始视频、再由 ffmpeg 后处理”：不要在
片段未确认前生成字幕、音轨或总片。流水线不插入 SVG 幕间卡，镜头之间直接硬切或短暂
交叉溶解。需要完整重建时再运行 `bash run-all.sh`；脚本
在缺少依赖时会自动执行同等的锁定版本安装。

产物在 `out/`：

| 文件 | 说明 |
| --- | --- |
| `raw/<id>.mkv` | 按真实状态时间戳封装的原始界面片段 |
| `shots/<id>.mp4` | 供审查的 1440×960、H.264 单镜头片段 |
| `tour-master.mp4` | **无字幕、无配乐的母版** |
| `tour.{zh,en}.srt` | 成片内嵌的软字幕，同时可作为外挂字幕；不是配音逐字稿 |
| `tour.{zh,en}.ass` | 可选硬字幕样式文件；默认合成不会把它烧进画面 |
| `subtitle-script.md` | 带镜头名与时间码的中英文字幕审阅稿 |
| `narration-script.md` | 独立于画面字幕的中文配音演讲稿 |
| `narration.zh.srt` | 配音录制或 TTS 的中文对时稿 |
| `music-selection.json` | 本次构建明确选择的音轨或静音 |
| `raelyn-tour-1440x960.mp4` | 单一成片，内嵌中文（默认）与英文可切换字幕轨 |
| `manifest.json` / `timeline.json` | 实测时长与合成时间线 |

## 为什么是这些参数

**全程 1440×960、1×。** 录制窗口和最终输出使用同一像素尺寸。UI 可读性
主要由逻辑窗口内的字号占比决定；额外做 2× 超采样会把每帧像素量放大到四倍，拖慢
浏览器交互，却不会增加最终成片的信息量。

**30fps 输出。** 星域旋转按 20 个独立画面/秒采样，再封装为 30fps；普通滚动只保留
关键位置，避免为重复画面浪费抓帧时间。时间轴前半段在待审片中局部 2×，后半段的
24H/本周卡片切换与连续旋转保持原速。

**按状态截图，不用连续录屏。** Playwright 先完成真实点击、滚动和状态切换，再对需要的
画面抓一张带逻辑时间戳的 JPEG；静止停留只延长该帧，不重复截图。随后用 ffmpeg concat
封装 VFR 原片并生成 30fps 待审 MP4。这样沿用 README 原视频成功采用的“原始片段 →
ffmpeg 后处理”路径，同时避免低码率 webm、无意义鼠标轨迹和空加载画面。

**settle 不进成片。** 每个镜头的加载、首帧绘制、标签收清都发生在 `settle` 窗口里，
抓帧从稳定画面开始——这就是「拼接过滤掉加载等待」。星域镜头额外等 Alpine 的
场景与标签元数据均完成，并核对页面实际加载的快照 ID；超时或快照不符会停止录制。

**页面保持完整。** 用量和智能体接入页都保留完整 1440×960 画面，通过页内滚动、页签
切换和稳定帧体现操作；不做会丢失上下文的固定裁切。

**字幕默认不烧进画面。** 单一成片 MP4 内嵌中文（默认）和英文两条可开关的 `mov_text`
字幕轨，视频流直接复用无字幕母版，因此改文案不会再次编码画面；同一份 SRT 也可作为
外挂字幕上传或编辑。
`make-subtitles.mjs` 仍生成 ASS，供确实需要固定样式硬字幕的场景手动使用。GitHub 和部分
浏览器播放器不一定展示 MP4 内嵌字幕，网页播放时应把 SRT 转成 WebVTT 后通过 `<track>`
加载；VLC、mpv、IINA 等本地播放器可以直接切换字幕轨。

**画面字幕与配音稿分开。** `captions` 是内嵌成片的中英单行信息层；
`narration` 是供朗读的中文演讲稿，用更短的连续句串起叙事。两者共享镜头时间线，但不互相
复制。结尾项目地址只出现在 `captions`，不朗读。`make-narration.mjs` 目前只生成审阅稿和
录音对时 SRT；录音、TTS 以及把人声混入成片尚未执行，`compose-tour.mjs` 也不会自动生成
人声。

**母版永远无字幕、无配乐。** 换文案、加一种语言、换一首配乐，都只要重跑
字幕、音轨选择与合成三个阶段，不用重录任何镜头。

## 分镜结构

三幕叙事、8 个连续界面镜头，配置时长合计约 59 秒，短转场重叠后约 57 秒。不插入
独立幕卡，叙事节奏完全由界面动作和字幕承担。

| 幕 | 镜头 | 讲什么 |
| --- | --- | --- |
| **I 认知** | `field-timeline` `field-topic` | 2× 回放 12 个月 → 24H/本周视频卡片与连续旋转 → 一级星域 → 二级主题 → 单个真实事件 |
| **II 追踪** | `stories-page` `playlist` | 故事阅读器与证据侧栏 → 周期简报 → Reuters 记录 → 切换并播放 WTI 原始视频 |
| **III 运行** | `library` `operations` `usage` `mcp` | 信源与视频列表滚动 → 待处理/运行中切到已成功 → 完整用量页 → MCP 客户端切换与完整页面滚动 |

星域内部相邻镜头的 `joinPrev` 设为 `0`，是**有意的硬切**：语义缩放本身就是转场，
再叠一层溶解只会糊掉星点细节。

## 录制用的真实内容

固定使用数据最完整的观测域，并锁定具体对象，保证每次重录讲的是同一个故事：

| 角色 | 对象 | 依据 |
| --- | --- | --- |
| 观测域 | `你需要关注的财经资讯`（`a811f131-…`） | 当前数据最完整的录制域 |
| 快照 | 固定 ready 快照 `c1e5f7d2-…` | 283,719 个真实事件；预检要求状态和 ID 完全一致 |
| 一级星域 | `Gold · 黄金 · commodities`（`276dda5e-…`） | 大宗商品语义区域 |
| 二级主题 | `5e6544a5-…` | 预检要求层级为 1 且父级是上述 Gold 星域 |
| 星点 | `白银价格突破66美元`（`638f5aae-…`） | 4 条来源记录保守归并 |
| 故事 | 国际金价（稳定身份 `5ae872f2-…`） | 当前修订含 23 个真实事件，跨快照继续阅读 |
| 播放列表 | `2026-09-10` | 90 条可播放记录 + 带 24 条结构化引用的简报；先固定 Reuters，再播放 CME Group 的 WTI Crude Oil |

**主题选的是大宗商品，不是地缘政治。** 窗口内事件量最大的几个一级星域是美伊、
美以、两岸相关主题；公开演示片带上政治指向没有必要，而黄金/白银同样密集、跨度完整，
且国际读者零门槛。换主题只改 `content` 里的几个 ID。

## 配乐

仓库**不分发任何录音**：古典作品的**曲子**早已进入公有领域，但**某一次演奏录音**
通常另有版权。请自行取得可用录音，放到 `assets/music/tour-bed.flac`（或用
`RAELYN_TOUR_MUSIC` 指定路径）。`select-music.mjs` 会检查音频流和剩余时长，并把选择
写入 `out/music-selection.json`；没有文件时会明确记录为静音。`compose-tour.mjs` 只接受
这份已经确认的选择，不会自行猜测或静默降级。

推荐（按契合度排序）：

1. **贝多芬第七交响曲 第二乐章 Allegretto** —— 首选。固定的顿挫音型上层层叠加声部，
   密度是一点点长出来的，和「事件不断进入星域、结构逐渐累积」的叙事完全同构；情绪
   庄重但不悲伤，60 秒截一段就有完整的起伏。
2. **德沃夏克第九交响曲「自新大陆」第四乐章** 开头 —— 你提到的那部，选第四乐章而不是
   第二乐章：第二乐章（Largo，「念故乡」）是挽歌气质，配产品片会显得沉重；第四乐章
   开头的铜管动机推进感强，适合做三幕结构的开场，但要注意它比画面「更大声」，混音
   增益要压得更低。
3. **霍尔斯特《行星组曲·木星》中段** —— 宽广、有宇宙感，和星域主题最直白地呼应，
   代价是它太有名，容易让人先想到别处。

可用录音来源：[Musopen](https://musopen.org)（明确标注公有领域的录音）、
[IMSLP](https://imslp.org)（注意逐条确认录音的授权而非只看乐谱）。选定后用
`music.startAt` 把最贴合 60 秒结构的一段裁出来，`music.gainDb` 默认 `-14dB`。

## 录制前必须处理的两件事

**隐私。** 片子会暴露真实的观测域内容——频道名、头像、视频标题、事件正文。确认可以
公开这些之后再录，并检查启动门面的 token 输入、设置页的端点与密钥、浏览器标签页与
本机路径都不入镜。脚本已经通过 cookie 注入令牌并跳过启动门面，正常不会拍到登录态。

**确定性。** 所有星域镜头都在 URL 中显式携带 `snapshot_id`，不会因为 current 快照
更新而切换内容。录制预检还会确认该历史快照仍是 `ready`，并确认主题、事件与快照航迹
确实属于它。故事阅读器故意展示同一稳定故事身份的最新修订，用来说明跨快照延续；资料库、
运行中心和用量页也读取实时状态。若希望这些实时页面保持一致，录制期间不要执行批量维护任务。

## 常见问题

**`playlist` 镜头播放器是黑的。** 当前 lockfile 对应的 Playwright Chrome for
Testing 已实测支持 H.264。若通过 `RAELYN_TOUR_BROWSER_CHANNEL` 换了其他浏览器，脚本
会重新探测解码能力；不支持时会在抓帧前停止，不能带黑屏继续生成成片。可改用确认支持
H.264 的系统 Chrome，并设置 `RAELYN_TOUR_BROWSER_CHANNEL=chrome`。

**某个动作没发生，日志里有 `[warn] 选择器未命中`。** UI 没有 `data-testid`，选择器
基于可见文案和结构，改版后会漂移。所有选择器集中在 `tour.config.mjs` 的 `SEL` 里，
改一处再单独重录该镜头：

```bash
node record-tour.mjs --shot playlist
```

局部重录要求 `out/manifest.json` 和其他镜头文件来自一次完整录制。新镜头会按配置顺序
合并回完整 manifest，不会再把 manifest 覆盖成单镜头清单；快照 ID 不一致时会拒绝混合。
若原片已经正确、只需重新编码待审 MP4，可移走对应 `out/shots/<id>.mp4` 后运行
`node record-tour.mjs --shot <id> --resume`；脚本会复用 `out/raw/<id>.mkv`。

**只想改字幕文案。** 改 `tour.config.mjs` 里对应镜头的 `captions`，然后
`node make-subtitles.mjs && node select-music.mjs && node compose-tour.mjs --reuse-master`，
不需要重录或重新编码画面。

**只想改配音演讲稿。** 改 `tour.config.mjs` 里对应镜头的 `narration`，然后
`node make-narration.mjs`；它只刷新文字稿和对时 SRT，不会重录镜头或合成配音。

**要出 GIF。** 先有完整视频，再从母版里截片段即可，例如取星域回放那 9 秒：

```bash
ffmpeg -ss 1.4 -t 9 -i out/tour-master.mp4 \
  -vf "fps=12,scale=1000:-1:flags=lanczos,split[a][b];[a]palettegen=max_colors=192[p];[b][p]paletteuse=dither=bayer" \
  -loop 0 out/hero.gif
```

## 文件

| 文件 | 职责 |
| --- | --- |
| `tour.config.mjs` | 分镜、时长、画面字幕、配音稿、镜头转场、配乐、选择器——唯一真源 |
| `record-tour.mjs` | 驱动页面、抓帧、编码单镜头 |
| `make-subtitles.mjs` | 由实测时长生成 Markdown 文字稿、ASS/SRT 与合成时间线 |
| `make-narration.mjs` | 由同一时间线生成独立的中文配音审阅稿与对时 SRT |
| `select-music.mjs` | 明确选择并校验音轨，或明确选择静音 |
| `compose-tour.mjs` | 拼接母版 → 内嵌中英可切换字幕轨 → 混配乐 → 输出单一成片 |
| `lib/ui.mjs` | Alpine 状态桥、必要点击与面板滚动；不生成鼠标移动轨迹 |
| `lib/preflight.mjs` | 通过真实 API 校验固定快照与全部核心录制对象 |
| `lib/manifest.mjs` | 合并全量/局部录制清单，并刷新当前创作元数据 |
| `lib/timeline.mjs` | 镜头与转场的绝对时间线，字幕与合成共用 |
