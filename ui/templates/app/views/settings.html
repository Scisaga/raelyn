YTDLP_COOKIES_YOUTUBE（cookies.txt）
仅用于 YouTube 的 yt-dlp 登录态（Netscape cookies.txt 格式）。
提示：保存后会写入数据库配置 /api/config/ytdlp_cookies_youtube，并在运行时写入本地 tmp/ytdlp_cookies_youtube.txt 供 yt-dlp 使用。
YTDLP_COOKIES_BILIBILI（cookies.txt）
仅用于 B站 的 yt-dlp / profile fetch 登录态（Netscape cookies.txt 格式）。
提示：保存后会写入数据库配置 /api/config/ytdlp_cookies_bilibili，并在运行时写入本地 tmp/ytdlp_cookies_bilibili.txt 供 yt-dlp / profile fetch 使用。
下载字幕（Subtitles）
下载字幕通常需要 Cookies，且更容易触发风控/限流（例如 HTTP 429）。建议默认关闭。
提示：开启字幕下载后，建议同时在上方配置 YTDLP_COOKIES_YOUTUBE，否则更容易失败/被风控。
会员视频（Members-only）
是否尝试下载 YouTube 会员专享视频（需要账号具备权限且 Cookies 有效）。默认关闭。
提示：关闭时，识别为会员专享的视频不会创建下载任务；打开后会尝试下载，若无权限则仍会跳过。
YTDLP_FORMAT（下载画质）
配置 yt-dlp --format（format selector）。可选 1080p/720p 上限或自定义。
非自定义：只读展示；自定义：可编辑
提示：该配置会保存在数据库配置中（/api/config），并在下载时作为 yt-dlp 的 --format 使用（无需重启即可生效）。
LLM 转写润色提示词
用于 video.polish_transcript 的全局提示词。保存后，对新的润色任务生效；历史任务不变。
提示：该配置会保存在数据库配置中（/api/config）。清空并保存后将回退默认提示词；建议保留 {chunk} 占位符，若遗漏，系统会自动把原始文本追加到末尾；{index} / {total} 可选，用于分段上下文。

推荐路径

按当前设备能力选择对应方式。
当前设备
Android / Chromium
Chrome、Edge 等支持浏览器可直接弹出安装提示，安装后从主屏幕进入。
1. 用支持安装的浏览器打开 RAELYN。
2. 点击地址栏或浏览器菜单中的安装入口。
3. 确认后将应用添加到主屏幕。
iPhone / iPad Safari
iOS 需通过 Safari 的系统分享菜单手动执行“添加到主屏幕”。
1. 使用 Safari 打开当前页面。
2. 点击底部或顶部的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 确认名称后点击“添加”。
iOS 非 Safari 浏览器
iPhone / iPad 只有 Safari 支持“添加到主屏幕”，其他浏览器需要切回 Safari。
1. 复制当前链接。
2. 切换到 Safari 打开同一页面。
3. 再执行“分享 -> 添加到主屏幕”。
